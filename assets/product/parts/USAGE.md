# 아틀리에 루나 파츠 출처·사용 조건

- 제작: 2DSketcher 프로젝트 작업 중 내장 ImageGen으로 생성. 생성 프롬프트와 채택 여부는 [generation-record.json](./generation-record.json), 실제 파일/상태/해시는 [catalog.json](./catalog.json)에 기록한다. 외부 API 키나 제품의 외부 생성 API 기능을 사용하지 않았다.
- 참조: 프로젝트가 보유한 PREMIUM-003 원화의 렌더링 스타일. 새 자산은 독립된 얼굴/머리/눈/입/의상/장식이며 기존 전체 초상/표정 패치를 파츠로 재등록하지 않았다. 특정 외부 캐릭터·상표·실존 인물을 제작 목표로 삼지 않았다.
- 용도: 이 프로젝트의 파츠 조합·로컬 편집/실행 개발·검증·자급 프로젝트 저장/복제에 사용하는 기본 라이브러리다. 원본 바이트는 해시로 보존하며 crop/배치/색상 조절은 별도 메타데이터와 공통 GPU 평가로 적용한다.
- 생성물의 제공자와 사용자 사이 권리, 입력 권한 책임, 출력의 비독점성은 적용 서비스 약관을 따른다. [OpenAI Terms of Use](https://openai.com/policies/row-terms-of-use/)와 서비스별 조건을 참고한다. 이 기록은 저작권 성립·독점성·제3자 권리 부재를 보증하거나 CC0 등 별도 공개 라이선스를 부여하는 문서가 아니다.
- 공개 제품 배포는 기존 출시·권리·서명·품질 게이트를 따른다. 이번 로컬 제작/패키지 확인을 공개 배포 승인으로 해석하지 않는다. AI 생성 사실과 제작 기록을 유지한다.

`*-clean.png` 4개는 눈/입의 주변 피부색 번짐을 줄인 채택본이고 `hair-*-front-v2.png` 2개는 이마의 작은 타원형 틈을 보정한 채택본이다. 앞선 6개 미채택 결과는 로컬 비교 자료로 남기고 제품 manifest에서 제외했다. 기록에는 프롬프트와 미채택 여부만 남긴다. 13개의 채택 PNG가 27개 상태 자원·12개 선택 항목·64개 기본 조합을 구성한다.
