초보자 관찰 기록

참여자가 앱에서 직접 작업하는 동안 관찰자가 시간·막힘·도움을 기록합니다. 실제 이름·연락처·얼굴 영상·음성을 저장하거나 전송하지 않습니다.

관찰 시작

U29-001의 과거 자기보고를 새 직접 관찰로 옮기지 않습니다. 첫 경로 파츠·한 장·분리 그림 각 10명을 모집하며 이후 경로는 학습 후 과제로 구분합니다.

과제와 구간 기록

00:00

    기록 저장·재관찰

    JSON 파일은 이 기기에만 저장합니다. 같은 ID의 기존 파일을 불러와 7일·14일 재관찰을 덧붙일 수 있습니다.

    관찰자가 확인할 과제
    1. 배정한 경로에서 캐릭터를 만들고 원하는 한 군데를 보정한다.
    2. 눈·입·고개를 움직여 보고 저장·닫기·재열기로 보존을 확인한다.
    3. 실제 OBS 미리보기에서 투명 아바타와 움직임·표정을 확인한다.
    4. INP를 저장하고 앱을 종료한 상태에서 Inochi Session으로 독립 사용한다.
    5. 실패·중단도 종료 기록에 포함한다. 앱 도움말은 허용하되 힌트·대리 클릭은 별도 기록한다.

    개발자/모의 기록·자기보고는 직접 관찰 성공률로 합산하지 않습니다. 기록 파일은 관찰자의 증언이며 참여자 신원을 인증하지 않습니다. 7일/14일이 지나기 전에는 관찰창 완료가 아닙니다.
