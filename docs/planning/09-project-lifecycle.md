## 사용 방법

`tools/dev.cmd run dev` 또는 패키지 EXE를 실행한다. 시작 화면에서 파츠·그림 한 장·분리된 그림 중 하나를 선택하고 초안을 만든다. **고급 예제 넣기**로 기존 고급 자산을 삽입하면 부위 선택·이름/역할·불투명도·위치·표정 값을 편집할 수 있다. 이 예제 삽입은 자동 분리/리깅이 아니다.

저장·다른 이름 저장·열기는 Windows 파일 선택창을 사용한다. `Ctrl+S`, `Ctrl+Shift+S`, `Ctrl+O`, `Ctrl+Z`, `Ctrl+Y`도 제공한다. 텍스트 입력 중에는 기본 텍스트 되돌리기 동작을 유지한다. 프로젝트 닫기/창 종료 시 변경이 있으면 네이티브 대화상자가 표시된다. 자동 복구가 있어도 사용자 저장 완료로 표시하지 않는다.

**복구본**에서 자동 복구·체크포인트·정상 백업을 선택해 비교한다. 보류는 편집/파일을 바꾸지 않는다. 복구본으로 계속하면 원본과 다른 새 파일을 저장한다. 복구 공간이 부족하면 최신 유효본을 지우지 않고 오류를 표시한다. 로컬 비공개 catalog에는 최근 파일 위치를 보관하지만 화면 IPC·정상 로그·휴대 묶음에는 절대 개인 경로를 전달하지 않는다.

## 제한과 후속

강제 종료는 실제 자식 프로세스에 수행했고 공간/권한 오류는 파일 저장 경계에 **ENOSPC/EACCES를 주입**했다. 실제 디스크 가득 참·물리적 전원 차단·백신·동기화 폴더·네트워크 파일 시스템 내구성을 검증한 것이 아니다. 원자 교체가 전원 상실까지 보장한다고 주장하지 않는다. 읽기 상한은 압축 256MiB·확장 512MiB·엔트리 1,024개이며 최대 크기에서의 성능 합격을 뜻하지 않는다.

새 Windows/별도 PC·VM·호스팅 CI는 미실행이다. 사용자 합의대로 현재 PC의 OS/DLL/드라이버를 유지한 격리 검증이다. 경로별 제작/자동 리깅·제품 추적/방송/외부 변환과의 전체 통합, 큰 프로젝트 성능·모든 실제 저장 실패 조건은 후속 T-268/T-271에서 검증한다. 52개 기능·12개 PD·15개 AC와 초기 세 경로·앱 실행/방송·외부 내보내기·장기 필수 범위를 유지하며 **M0 통과 또는 공개 출시 승인이 아니다.**
