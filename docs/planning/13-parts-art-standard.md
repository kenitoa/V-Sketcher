# 13 파츠 아트·좌표·호환 규약 — T-121~123

아틀리에 루나 `atelier-luna / 1.0.0`, 공통 몸체 규격 `atelier-bust-v1`을 첫 라이브러리로 고정한다. DEC-04의 얼굴/피부 2·앞뒤 머리 세트 2·좌우 눈 세트 2·입 세트 2·의상 2·장식 없음/있음 2를 충족하는 64개 기본 조합이다. 이름만 바꾼 동일 그림이나 기존 전체 초상 패치는 선택지 수에 포함하지 않는다.

## 캔버스·연결·순서

1024×1280px, 좌상단 원점, +x 오른쪽/+y 아래, 캐릭터 기준 좌우다. 얼굴/목 윤곽은 x340~684, y130~655, 눈의 기준 중심은 화면 x438/586·y360, 입 x512·y480이다. 머리/눈/입/장식은 얼굴의 자식이며 의상은 몸체 기준의 별도 root다. 얼굴 기준 부위는 제거하지 않고 교체한다. 앞뒤 머리는 한 세트만 제공한다.

| 레이어 | z | 기준 영역/연결 |
|---|---|---|
| 뒤 머리 | 0 | x150,y70,724×1180, 얼굴 부모 |
| 얼굴·목 | 10 | x340,y130,344×525, 얼굴 root |
| 의상 | 20 | x130,y595,764×655, 목 아래 겹침 여유를 둠 |
| 오른눈/왼눈 | 30 | 화면 왼쪽/오른쪽, 별도 부위·별도 제어 |
| 입 | 40 | 닫힘/미소/열림, 별도 상태 |
| 앞 머리 | 50 | x187,y70,650×740, 눈을 가리지 않는 제한 배치 |
| 장식 | 60 | x674,y180,90×154, 머리 위 브로치 |

PNG는 수정하지 않는다. 읽기 전용 알파 측정으로 상태별 sourceRegion과 source→편집 변환을 정의하며 저장된 좌표가 원본 PNG의 상태/부위 영역을 참조한다. 눈 2개 아틀라스는 각 3상태×좌우, 입 2개 아틀라스는 각 3상태다. 동일 PNG의 다른 상태/영역은 고유 자산 ID로 구분하며 GPU 텍스처는 원본 파일별 한 번 로드한다.

## 색상·조절·움직임

| 부위 | 이동 각 축 | 크기 | 정적 회전 | 색조 |
|---|---|---|---|---|
| 얼굴 | ±2px | ±1% | ±0.5° | 피부색 보존, 제공 안 함 |
| 앞/뒤 머리 | ±3px | ±1% | ±0.5° | 지정 유색 영역 ±12° |
| 좌우 눈 | ±2px | ±3% | ±1° | 홍채 유색 영역 ±18° |
| 입 | ±2px | ±3% | ±1° | 입술 영역 ±6° |
| 의상 | ±4px | ±2% | ±0.5° | 자색/청록 원단 ±12° |
| 장식 | ±6px | ±5% | ±2° | 자수정 영역 ±10° |

색상 영역은 HSV hue 범위·최소 채도로 명시한다. 피부·무채색 선/하이라이트·금색/은색은 대상에서 제외한다. 원본을 직접 칠하지 않고 straight color에서 계산한 뒤 원래 alpha로 다시 premultiply한다. 색상 변경으로 실루엣 alpha를 바꾸지 않는다.

양쪽 눈은 기본 연동이며 가로 이동·회전은 대칭, 세로 이동·크기·색조는 같은 값이다. 연동을 켤 때 선택한 눈을 기준으로 맞추고, 눈 외의 부위가 선택됐으면 캐릭터 왼눈이 기준이다. 항목별 기본값·선택 부위 전체·모든 부위 조절 초기화를 구분한다. 범위 밖/비정상 값은 거부하고 이전 정상값을 유지한다.

조절 초기화는 x/y/회전/색조를 0, 배율을 1로 되돌린다. 파츠 선택·좌우 연동 모드·사용자 이름/불투명도는 유지한다. 라이브러리의 위치 변경은 전용 조절을 사용하며 공통 행렬의 가로 성분을 직접 수정하는 경로는 차단한다.

공통 눈 열림/독립 깜빡임·입·고개 제어를 연결한다. 눈의 중간 상태는 반감김, 입의 중간 상태는 미소다. closed→middle→open을 두 구간으로 연속 보간한다. 고개는 기준 얼굴 폭 344px의 ±4.5%와 ±6°를 사용하며 몸체 하단은 고정한다. 물리/보조 흔들림은 초기 미제공 결정을 유지한다.

## 버전·호환·제거

라이브러리/몸체/캔버스 규격이 다르면 선택을 차단하고 현재 모습을 유지한다. 자급 프로젝트는 그림과 메타데이터가 있어 카탈로그가 바뀌어도 표시할 수 있지만 알 수 없는 버전을 조용히 현재 파츠로 치환하지 않는다. 기본 조합을 새로 준비하는 경로와 변경 전 checkpoint를 제공한다.

교체 시 의미가 같은 매개변수 ID·범위·표정·입력/감도·기본 자세와 유효한 부위 transform 연결을 보존한다. 상태 이름만 새 파츠에 다시 연결한다. 제거하면 해당 부위 연결을 끊고 지원 동작/전용 매핑 손실을 표시한다. 다시 장착하면 보관된 의미 매개변수로 연결한다. 필수 부위를 제거한 사용자 조합은 기본 64조합 검수 밖이며 제한을 표시한다.

모델 1.3의 `assembly`, 부위 `library/color`, 중간 상태 매핑에 저장한다. 이전 1.0~1.2는 읽을 수 있고 업그레이드는 다른 파일로 저장한다. 조합 재사용은 실제 프로젝트 저장·복제로 제공하며 별도 프리셋이 있다고 표시하지 않는다. 출처/프롬프트/사용 조건은 [자산 기록](../../assets/product/parts/USAGE.md)을 따른다. 이 규약과 로컬 검수를 ART-01 독립 평가·외부 변환 동등성·M0 통과로 확대하지 않는다.
