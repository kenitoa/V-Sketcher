## 사용 방법

**분리 그림 → PNG 폴더 / .2dparts 열기 / 분리 자료 예제**에서 시작한다. 고급 예제는 기존 프리미엄 파츠를 원래 좌표대로 잘라 구성한 16레이어다. 새로 그린 저품질 구조 도형을 기본 아트로 사용하지 않는다. 소개 헤드라인·슬로건을 추가하지 않았으며 필드/버튼·오류·제한·확인 안내만 제공한다.

**분리 그림 · 배치와 연결**에서 부위를 고른다. 이름이 같아도 번호와 고유 ID로 구분한다. 원래 좌표가 없는 자료는 추정으로 표시하고, 공통 캔버스 또는 잘린 조각 방식을 확인한 뒤 확대·드래그·방향키(Shift 10px)·수치로 위치를 맞춘다. 역할과 캐릭터 기준 좌우를 확인한다. 미러는 보기만 바꾼다.

표정 대체 그림은 사용 방식을 바꾸고 대표 부위와 열림/닫힘/중간을 지정한다. 대표로 중복 지정한 눈/입·부모/그룹 순환·누락 연결은 적용 전에 고친다. 빈 부위·숨김·미지정 장식은 원본과 함께 보존된다. 비인간형·누락 표정은 사용할 수 없는 동작과 제한을 확인하고 진행할 수 있다.

**확인한 배치로 움직임 준비**를 누른 뒤 현재 결과와 새 후보를 나란히 시험한다. 설정을 바꾸면 다시 준비해야 한다. **확인한 결과만 프로젝트에 적용**하기 전까지 기존 작업은 바뀌지 않는다. 작업실의 공통 움직임 화면에서 눈·입·고개를 시험하고 `.2dsketch`로 저장한다. 적용 후 되돌리기/다시 실행·복사·재열기·적용한 연결 재확인이 가능하다. 고급 망 변경은 재안내로 덮어쓰지 않는다.

**분리 PNG 묶음 저장**은 원본과 배치·역할 자료의 `.2dparts` 교환이다. 독립 아바타 내보내기는 후속 INP 기능이며 이 저장으로 완료 처리하지 않는다. [상세 형식·지원 한도·보존 계약](../architecture/split-image.md).

## 검사와 범위

정식 결과는 [verification.json](../../evidence/phase16/verification.json), [개발 앱](../../evidence/phase16/development-run.json), [패키지 검사](../../evidence/phase16/package-audit.json), [문서/동결 감사](../../evidence/phase16/audit.json)에 기록한다. `tools\dev.cmd run check`로 기존 포함 Node 147·Python 31, 총 **178개 검사 그룹**을 실행한다. 신규 분리 검사는 Node 18·Python 5다. 전체 개발 앱의 기존 경로 회귀와 분리 화면을 검증하고, release는 같은 PC에서 개발 도구 PATH를 제거한 새 프로필 두 개(기본/1080×720)로 **분리 기능+기반 코어**를 검사한다. release에서 이전 경로 UI는 NOT_RUN으로 명시한다.

매 실행에서 manifest 예제와 수동 수선 폴더 각각 GPU 25상태를 독립 원본 합성과 비교한다. 눈/입·고개 극단, 중립 평균 오차 <1/255, alpha 평균 오차 <1/255, GL 오류 0·버퍼 재업로드 없음이 기준이다. 결과와 실제 화면은 [분리 편집](../../evidence/phase16/split-ui.png), [극단 상태](../../evidence/phase16/split-extremes.png)에 보존한다.

`scripts/split-preservation-check.mjs`의 [추가 보존 검사](../../evidence/phase16/preservation.json)는 비어 있지 않은 비대칭/잠금 표정과 입력 매핑·fallback, 기본값이 아닌 세기·평활화·자세를 넣고 장식 위치를 바꿔 재안내해 기존 값과 부위/매개변수 ID 보존을 확인한다. 표정 UI 완료로 해석하지 않는다.

지원 샘플과 자동 조작 검증이며 사람의 초보자 관찰·독립 ART-01·임의 원화 전체 구조화·진짜 3D 회전·숨은 원화 복원·자유 망/표정 편집 완료 주장이 아니다. 장치/방송/독립 아바타 내보내기·내외부 동등성·FPS/M0·전체 T-268/271 통합 검증은 후속이다. 이전 experiments 02~05와 evidence 06~15는 동결 보존한다.
