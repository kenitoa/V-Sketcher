## 사용 방법

새 프로젝트에서 **고급 예제 넣기 → 움직임 시험**을 선택한다. 예제는 기존 고급 원화와 준비된 눈/입 그림을 사용하는 수동 작성 예제다. 경로별 자동 그림 분리·리깅을 새로 실행한 결과가 아니다.

슬라이더와 최소/기본/최대 버튼은 **일시적인 시험 입력**이다. 개별 예제 또는 전체 동작을 재생하고 반복 여부를 선택한다. **중지·기본 자세**는 즉시 저장된 기본 자세를 적용하고 평활화 이력을 초기화한다. 원본 비교나 다른 편집 단계로 이동해도 시험을 종료한다.

**움직임 조절과 기본 자세**를 펼쳐 세기·부드러움 시간을 바꾸거나 현재 시험 목표값을 기본 자세로 저장한다. 이 동작만 편집 이력/저장 대상이 된다. 매개변수 범위는 고급 설정에서 수정할 수 있다. 범위를 바꾸면 연결된 저장 표정/기본 자세/fallback도 범위 안으로 제한하며 undo로 되돌릴 수 있다. 설정 변경 후 재생은 기본 자세에서 다시 시작한다.

이전 1.0 프로젝트도 열 수 있다. 망이 없으면 **기본 움직임 망 준비**를 선택한다. 기존 자료를 덮어쓰지 않는 기본 제안이며 수정 전 영구 복구 지점을 만든다. 1.1 변환본은 **다른 파일에 저장**해야 한다. 새 minor는 미지 필드를 보존한 읽기 전용, 새 major는 차단하는 정책을 유지한다.

## MOT-DEC-01: 초기 보조 흔들림 미제공 — T-109

현재 고급 예제의 머리카락·의상은 원화에 함께 그려져 있으며, 실제 출시용 분리 머리카락/장식 파츠와 충돌·고정점 검수 자료가 아직 없다. 전체 초상을 흔드는 효과를 머리카락 물리라고 표시하면 원화 관계를 훼손하고 준비되지 않은 표현을 제공하게 된다. 따라서 초기 공통 평가기는 **secondary=disabled**로 저장하며 보조 흔들림을 제공하지 않는다.

파츠/분리 제작 단계에서 독립 자원·고정점·영향 범위가 확보되면 별도 검토한다. 도입 시 재시작/프로젝트 전환 초기화, 급격한 입력·긴 dt·중지/부하 제한, 겹침·관통·원화 품질을 실제 자산으로 검증해야 한다. 이번에는 solver의 성능/안정성을 검증했다고 주장하지 않는다. 이 결정은 필수 눈·입·제한 고개와 세 입력 경로·앱 실행·방송·외부 내보내기 범위를 축소하지 않는다.

## 제한

기본 망은 로컬 사각 영역의 규칙 격자와 상부/하부 영향 제안이다. 얼굴 기준 폭은 준비된 눈 중심 간격으로 추정하고 없으면 캔버스 폭을 기준으로 제안한다. 이미지 의미를 새로 분석하거나 가림의 실제 옆면을 복원하지 않는다. 수동 작성 고급 상태 그림의 연속 보간을 모든 그림의 최종 품질로 보증하지 않는다. 출시용 파츠·자동 준비/망 보정·품질 표본 확대와 내부/외부 변형 동등성은 후속이다.

이 검증은 실제 GPU·로컬 파일·프로그램 방식 UI 시험이다. 물리 카메라/마이크·새 OBS 출력·외부 Session 구동·새 Windows/별도 PC·호스팅 CI·초보자 과제·전체 DPI/접근성 인증·M0 FPS/장시간 기준은 재검증하지 않았다. **M0 HOLD·5개 OPEN**, T-268/271의 전체 통합/현실 실패 검증을 유지하며 T-111~410을 완료 처리하지 않는다.
