## 사용 방법

한 장 경로에서 자동 준비 결과를 적용한 뒤 **모양 고치기 · 넓은 보정 화면 열기**를 누른다. 확인이 필요한 눈/입부터 선택한다. 좌우는 캐릭터 기준이며 캐릭터의 왼쪽 눈은 정면 그림의 오른쪽에 보인다.

**위치·크기 다시 그리기**로 원화 위에서 드래그하거나 수치를 바꾼다. **현재 영역 이동**은 크기를 유지하고 이동한다. 확대/축소·화면 이동으로 작은 부위를 맞추고, 원화 영역에 초점을 둔 뒤 방향키(Shift는 10px)로 이동할 수 있다. 아래 원본 파일 좌표는 EXIF/축소/crop을 반영한다. 값은 그림 안에 있어야 하며 기본 영역/마스크는 가로 8px·세로 5px 이상이다.

머리카락 등 움직이면 안 되는 조각은 **움직임 영역 빼기**로 사각형을 지정한다. 원래 원화에 남고 눈·입 표정에서 제외된다. **움직임 영역 추가**는 필요한 사각형만 더한다. 32개 이내의 원본 좌표 마스크를 기록하며 영역을 옮긴다고 원본의 가림 좌표를 조용히 이동하지 않는다. 앞뒤 순서 값이 클수록 앞으로 그린다. 서로 겹친 눈/입 영역은 위치를 다시 맞춰야 한다.

보이지 않는 부위를 보이는 것으로 자동 확정하지 않는다. 실제로 보이는 부위의 위치를 사용자가 확인하거나 **가림으로 차단**/**건너뛰기**로 표정을 정지한다. 차단한 부위의 동작 제한과 제한 고개를 확인한다. **이 부위 보정 미리보기** 후 현재/후보를 비교하고 체크한 부위만 적용한다. 적용 전에는 프로젝트/원본 파일을 바꾸지 않는다. 공통 바탕은 선택한 결과와 현재 미선택 부위에 맞춰 함께 재생성한다.

**이 보정을 재분석에서 보호**가 기본이다. 선택 부위 또는 전체 재분석은 보호된 항목을 유지하고 나머지만 재검사한다. 필요할 때 **선택 부위의 보호된 보정도 덮어쓰는 후보 준비**를 켜고 비교한다. 이것은 후보 생성 동의이며 실제 교체는 다시 체크한 부위만 적용해야 한다. 얼굴 추론은 전체 그림이 필요하지만 표정 자원 재생성은 지정 부위에 한정한다.

현재 입력 취소·후보 폐기·최초 자동 결과 복원은 서로 다르다. 해당 부위/전체 자동 복원도 후보 비교 후 적용한다. 적용된 보정은 되돌리기/다시 실행·복구본으로 돌아갈 수 있다. 원본과 이전 자원을 보관하고 `.2dsketch` 저장/복제/재열기에 마스크·보호·출처/좌표·제한·표정/망을 함께 보관한다.

## 제한과 해석

이 단계는 한 장 그림에서 이미 분석 가능한 얼굴의 눈/입 위치·경계와 제한 표현을 수정한다. 얼굴 자체를 찾지 못한 입력의 수동 얼굴 생성·자유 곡선/브러시·의미별 앞뒤 머리 분리·임의 메쉬/부모/연결 편집·가려진 원래 모습 복원은 완료 기능이 아니다. 사각 마스크와 확인 가능한 부위를 먼저 제공하며 인식되지 않은 얼굴/완전 가림은 다른 원화/입력 경로로 안내한다. 분리 입력과 세부 구조 편집은 16~17단계에 유지한다.

추정 눈꺼풀/입 안의 원화 인상·정교한 가닥 경계·GPU 샘플링 편차는 [14단계 제한](./14-single-image.md)을 유지한다. 실제 초보자 관찰·독립 ART-01 평가자 3명·전체 동적 품질/M0 FPS·방송/외부 표현 동등성·장시간·새 Windows·호스팅 CI·서명/공개 배포 승인은 후속이다. 호환/내보내기 검사 무효화를 전체 외부 지원으로 해석하지 않는다. **M0 HOLD·5개 OPEN·T-151~410 미완료와 T-268/271 전체 통합 검증을 유지**한다.
