## 1. 출처·권한·고품질 이미지 기준 — T-011

사용자 원본을 임의로 찾거나 다운로드하지 않고 두 출처로 시험 자산을 마련했다. [권한·용도 기록](../../experiments/phase02/assets/RIGHTS.md)과 [입력 manifest](../../experiments/phase02/assets/manifest.json)에 각 샘플의 출처 ID·목적·허용 범위·파생 관계·SHA-256을 연결했다.

| 출처 | 확보한 자산 | 사용 범위·제한 |
|---|---|---|
| SRC-PROCEDURAL-001 | 이 프로젝트에서 작성한 생성 코드로 그린 캐릭터·파츠·구조 오류 사례 | 프로젝트 개발·실험·회귀 검증·문서·저장소의 시험 자료. 외부 원본·폰트·사진·캐릭터 미사용. 완성 제품 아트가 아님 |
| SRC-IMAGEGEN-001 | 사용자 추가 지시로 ImageGen을 사용해 만든 고품질 캐릭터 원화 2건 | 프로젝트 기술 평가·이미지 품질 검토·문서. [생성·편집 프롬프트](../../experiments/phase02/assets/premium/generation-prompts.md)와 [샘플별 검토](../../experiments/phase02/assets/premium/catalog.json) 보존. 모델 학습에 자동 편입하지 않음 |

사용자는 이번 작업 중 “이미지의 경우에는 … 고급지게 해야 돼. GPT Image 2.0느낌이 나와야 돼”라고 품질 기준을 추가했다. 이를 **섬세한 선화·눈동자·머리카락·명암·의상 재질과 장식의 완성도 및 처리 후 원화 인상 보존**으로 구체화했다. 특정 생성 모델을 제품에 연결했다는 뜻은 아니다. 기본 제공 생성 도구는 실제 모델 식별자를 노출하지 않아 `GPT Image 2.0`으로 생성했다고 단정하지 않는다.

| 고품질 입력 | 용도와 시각 검토 |
|---|---|
| [HQ-001 원화](../../experiments/phase02/assets/premium/HQ-001-premium-portrait.png) | 1254×1254 RGB. 세밀한 얼굴·머리카락·자수 의상과 불투명 배경을 가진 고품질 입력 후보. 상단 여백이 좁고 하단은 상반신 크롭. 처리 전후 인상·미세 디테일 비교에 사용 |
| [HQ-002 경계 스트레스](../../experiments/phase02/assets/premium/HQ-002-alpha-edge-stress.png) | 1254×1254 RGBA, 실제 알파 포함. 일부 머리카락·장식 가장자리에 색 번짐·반점이 있어 스트레스 입력으로 분류. 깨끗한 투명 경계의 정답 이미지로 승인하지 않음 |

고품질 원화가 있다는 이유로 리깅이나 분리 파츠가 완성된 것으로 표시하지 않는다. 아래 절차 제작 파츠는 좌표·구조·상태 전환용으로 사용하며 사용자에게 보여줄 고급 제품 아트의 품질을 대신 입증하지 않는다.

## 2. 한 장 그림 검증 세트 — T-012

[한 장 그림 미리보기](../../experiments/phase02/fixture-contact-sheet.png)로 시각 점검했다. 기본 캐릭터에서 파생한 절차 제작 입력 16건과 고품질 원화 2건으로 첫 대표 세트를 구성했다. 실제 사용자 그림·다양한 작가·모든 화풍을 대표하는 통계 표본은 아니다.

| S-002 | 불투명 배경 | 배경 분리와 원화 경계 보존 |
| S-003 | 15도 기울기 | 얼굴·눈·입 위치와 편집 좌표 일치 |

| S-009 | 음영 추가 | 명암과 부위 경계 혼동 여부 |

## 3. 분리 그림과 최소 파츠 — T-013/014

좌표 규칙은 **이 시험 세트에서만** 왼쪽 위 원점, 오른쪽 +X·아래쪽 +Y의 픽셀 좌표다. 좌우는 캐릭터의 신체 기준이며 정면에서는 캐릭터 왼눈이 화면 오른쪽이다. 제품 지원 형식은 DEC-03에서 후속 결정한다.

| 입력 ID | 구조 조건 | 준비 검사에서 기대하는 결과 |
|---|---|---|
| L-001 | 정상 PNG 부위 묶음·역할·순서·공통 캔버스 | 오류·경고 없음 |
| L-002 | 불명확한 이름·역할 누락 | 역할 확인 필요 경고 |
| L-003 | 좌표 누락 | 좌표 누락 오류 |
| L-004 | 비어 있는 선택 장식 | 빈 레이어 경고, 나머지 구조 유지 |
| L-005 | 중복 부위 ID | 참조 식별 충돌 오류 |
| L-006 | 입 부위 누락 | 입 움직임 제한 경고, 전체 데이터를 임의 폐기하지 않음 |
| L-007 | 이미지 리소스 누락 | 누락 리소스 오류 |
| L-008 | 좌우 표기 충돌 | 정면 좌표와 좌우 표기의 충돌 경고 |
| L-009 | 크기가 다른 잘린 부위·0이 아닌 원점 | 좌표를 적용하면 L-001과 픽셀 내용 일치 |
| L-010 | 구조는 유효하지만 앞머리 순서가 잘못됨 | 구조 검사 통과. 시각적 겹침 품질은 후속 평가에서 별도 판정 |

파츠 라이브러리 `PARTS-001`은 기본 부위 8개(뒤머리·몸체·머리·양쪽 열린 눈·닫힌 입·앞머리·장식)와 양쪽 감은 눈·열린 입의 대체 3개, 총 11개 파츠를 제공한다. 모든 파츠에 역할·좌우·상태·바운딩 박스·원점·출처·해시가 있다. 열린/감은 눈과 닫힌/열린 입의 상태, 머리·몸체·앞뒤 머리 겹침을 시험할 수 있다. 현재는 상태 이미지 준비이며 제품의 실제 움직임·파츠 교체 구현은 T-021~024에서 수행한다.

레이어 파일을 지원한다고 선언하지 않고 PNG+시험용 JSON 묶음으로 구조 실험을 시작한다. PSD·상용 도구 형식은 후보 조사·검증 후 별도로 결정한다.

## 4. 기준 장비 후보와 주변 장치 — T-015

| 항목 | 실제 수집 결과 / 해석 |
|---|---|
| OS | Windows 11 Pro, 10.0.26300, 빌드 26300, 64비트 |
| CPU / RAM | Intel Core i5-13420H, 8코어·12논리 프로세서 / OS 가시 메모리 31.71GiB |
| GPU | Intel UHD Graphics 및 NVIDIA GeForce RTX 4050 Laptop GPU. NVIDIA 도구 보고 메모리 6141MiB |
| GPU 드라이버 | Intel 32.0.101.6078 / NVIDIA WMI 32.0.16.1078, NVIDIA 도구 610.78. 수집 방식별 표기 보존 |
| 카메라 | 현재 연결된 `HD Webcam`, PnP 상태 OK. 미디어 드라이버 목록의 USB Video Device 10.0.26100.9974 포함 |

## 5. 실험 개발 환경과 완료 증거 — T-016~020

실험 코드는 `experiments/phase02/`, 원본 입력은 `assets/`, 준비 검사 결과는 `results/`로 구분했다. 제품 코드·렌더러·자동 리깅 엔진을 미리 선정한 구조가 아니다. `.venv-lab`은 글로벌 패키지와 분리된 Python 환경이며 Python 3.14.10·Pillow 13.0.0에서 생성·검사를 실행했다. Windows CPython 3.14용 Pillow 휠의 SHA-256을 고정한 잠금 파일과 배포 아티팩트 기록도 남겼다.

| 작업 | 완료 산출물·실행 증거 |
|---|---|
| T-011 | 출처 2개, [권한·용도](../../experiments/phase02/assets/RIGHTS.md), manifest의 샘플별 출처·목적·해시 |
| T-012 | S-001~016, HQ-001/002 실제 이미지와 위 조건표·미리보기 |
| T-013 | L-001~010 실제 구조·오류 입력, 좌표 등가성 확인 |
| T-014 | PARTS-001 11개 파츠와 역할·상태·겹침 기준 |
| T-015 | ENV-WIN-001 장비·장치·드라이버·미시험 조건 기록 |
| T-016 | [실행 코드·절차](../../experiments/phase02/README.md), requirements·휠 해시 잠금, 격리 환경 실행 |
| T-017 | [방송·외부 아바타 후보 비교](./02-candidates.md) 1~2절, 공식 출처 확인 |
| T-018 | 같은 문서 3절의 분석·추적·변형 기능·제약·환경·배포 조건 비교 |
| T-019 | [품질·성능 평가 양식](./02-evaluation.md)과 기계 판독 가능한 run-template.json |
| T-020 | 같은 문서의 고정 재현 절차, 입력·구성·환경·예상 결과를 연결한 실행 기록 생성과 준비 검사 |

[준비 검사 결과](../../experiments/phase02/results/readiness-001.json): 입력 29건의 예상 오류·경고가 모두 일치했고 자산 50개 해시 및 L-001/L-009의 좌표 등가성을 확인했다. [재생성 확인](../../experiments/phase02/results/reproducibility-001.json)에서는 절차 자산 재생성 전후 manifest와 입력 해시의 동일성을 확인한다. 고품질 생성 이미지는 재생성하지 않고 저장된 파일 해시를 유지한다.

현재 확인한 것은 **준비 도구의 파일·구조 검사**다. S-016의 캐릭터 부재, L-010의 잘못된 시각 순서, HQ-002의 경계 결함을 이 검사로 판정했다고 표시하지 않는다. 자동 인식·움직임 품질은 03, 장치·방송·외부 독립 구동은 04, 지원·기술 확정은 05에서 각각 검증한다.
