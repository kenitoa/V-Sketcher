## 5. 결정 기록과 변경 규칙

결정할 때 `ID / 결정일 / 담당 / 상태(미정·실험 중·확정·재검증) / 후보 / 실제 환경·버전 / 샘플·권한 / 재현 단계 / 결과·증거 위치 / 채택 이유·미채택 이유 / 지원·제외·손실 / 연결 PRD·Function·Todo / 재검증 조건`을 남긴다.

지원 대상·버전·의존 요소가 바뀌거나 원본·호환·초보자 완주 문제가 생기면 관련 결정을 다시 연다. 필수 기능을 축소할 필요가 생기면 이유와 사용자 흐름 영향을 명시하고 PRD·Function·Todo·수용 기준을 함께 검토한다. 미정 항목을 확정 지원처럼 안내하지 않는다.
