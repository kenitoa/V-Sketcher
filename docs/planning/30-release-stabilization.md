## 후보와 판정 방법

30단계의 변경은 `tools/`·`scripts/`·검증/운영 문서다. 기존 제품 바이트를 수정하거나 버전만 올리지 않는다. `tools/release-controls.mjs`는 필수 조건이 누락되면 NOT_RUN/HOLD로 남기며 PASS에는 현재 후보 해시와 파일 해시 근거가 필요하다. 다른 후보·과거 증거·빈 근거·중복/잘못된 ID로 PASS를 만들 수 없다. 게이트 준비와 게시 권한은 별개이며 도구에 서명/게시/업로드 기능은 없다.

현재 앱 버전·지원 표·worker·모델·라이선스 고지·자산과 ZIP의 정확한 바이트를 확인한다. 앱·worker 재현은 개발 도구 PATH를 제거한 같은 PC의 격리 프로필에서 수행한다. 깨끗한 Windows, 다른 장치, 최소 사양, 실제 외부 실행기·OBS 재시험이라고 표시하지 않는다. 과거 27의 OBS/외부 대상 실증과 28의 34회 강제 종료/복구·60회 반복·단기 WebGL 지표는 기존 실행의 범위와 해시를 그대로 연결한다.

## 알려진 문제와 안정화 순서

1. **INT27-CAM-01 / P1**: 실사 얼굴 미리보기 정상 자기보고에 비해 앱 검출 0명. DirectShow index 0의 성공과 같은 물리 장치인지 미확인. 장치 없는 실행은 임시 우회이며 해결이 아니다. 동일 장치·브라우저 프레임 경로를 확인한 후 추적/보정/손실·복귀와 실제 음성 반응을 재시험한다.
2. **실행·성능**: 각 경로 2시간 실제 장치/OBS 기록, 센서→방송 전체 및 독립 체감 지연, 지원 입력/복잡도·동시 작업·프로세스 트리/GPU 누적을 측정한다. 12초 렌더 지표나 과거 CPU 14.08FPS를 현재 GPU 빌드 전체 성능으로 쓰지 않는다.
3. **데이터·설치**: 0.21→0.22 및 동일 스키마 호환과 제어된 실패 증거를 유지하고, 안전하게 격리한 실제 공간 부족·깨끗한 Windows·다른 PC/장치·서명 검증을 보완한다. 기존 사용자 자료를 임의 이동/삭제하거나 OS 보호를 완화하지 않는다.
4. **사용성·품질**: 경로별 10명/총 30명과 7일·14일 관찰창, 작업/대기/막힘·보정·이탈, 독립 평가자 3명의 고급 아트 30개 평가를 확보한다. U29-001의 성공 응답만으로 이 조건을 충족하지 않는다.
5. **운영·배포**: 권리/고지·서명·지원 담당/접수 채널·제한 시험과 피드백을 준비하고 전체 게이트를 재검토한다. 공개 문의 주소나 수신자를 만들지 않는다. [AGENTS.md](../../AGENTS.md)의 “Do not publish, push, sign or deploy as part of a local build task.”에 따라 이 작업에서는 게시·서명·배포를 수행하지 않는다.

## 초기 2D 현황 보고와 장기 착수 기준

초기 2D는 **안정화 검증 중/HOLD**다. 공통 프로젝트·저장/복구·GPU·세 제작 경로·보정·표정/입력·실행·방송 페이지·PNG/INP·안내/포터블이 구현돼 있지만 실제 사용자 완주와 현재 후보의 모든 지원·품질·장치·성능·새 OS·운영 기준은 충족하지 않았다. 이 보고로 30 종료나 31~40단계 제품 완료를 승인하지 않는다.

장기 3D/자체 모델 생성은 유지한다. 착수 전 2D 미해결의 책임·분리 가능한 탐색 범위를 명시하고, 2D 원본과 새 파생 스키마/런타임을 분리한다. 공통 ID·좌표/색·자산 출처·리비전/CAS·취소/캐시·프로세스/GPU 예산·안전 저장/복구·프로젝트 호환·권한·독립 내보내기의 회귀를 유지한다. 3D는 깊이/가림/추가 시점·리그/표정·외부 형식 손실, 자체 모델은 데이터/학습 권한·로컬/서버 경계·재현/모델 버전·사용 조건·자원/비용·입력/출력 출처를 새 기준으로 검증한다. 기존 2D 통과나 생성 이미지 도구 사용으로 장기 기능의 성공을 대체하지 않는다.
