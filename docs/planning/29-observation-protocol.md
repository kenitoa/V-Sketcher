# 초보자 관찰 계획 v1.0

T-281~284 / 2026-11-18. [01 측정 계약](01-metrics.md), [05 출시 기준](05-release-gates.md)을 유지한다. M0 HOLD. 개발자 회귀 시험과 사용자 자기보고는 직접 관찰과 별도 집계한다.

**참여 상태 갱신:** 계획 시점의 자격·동의 확인 전 0명에서, 대화 중 U29-001이 초보자 자격·익명 기록 동의와 파츠 과제 성공을 자기보고했다. 직접 수행·저장 화면과 시간·보정량은 확인되지 않았고 다른 두 경로·방송·독립 실행은 미관찰이다. 사용자 요청에 따라 추가 확인·보완을 추후로 남겼으며 출시 표본 충족이나 정량 성공으로 합산하지 않는다. 등록 기록과 응답 기록은 `evidence/phase29/run-01/participant-U29-001*.json`에 구분해 보관한다.

모집 대상은 리깅·버튜버 제작 도구를 처음 쓰는 사람이다. 출시 검증 표본은 30명, 첫 경로 파츠/한 장/분리 그림 각 10명이다. 한 사람이 세 경로를 수행해도 최초 경로만 첫 사용 표본에 포함하고, 나머지는 학습 후 교차 과제로 분리한다. 이번 즉시 가능한 참여자는 자격·동의 확인 전 0명이며 출시 표본 달성으로 간주하지 않는다. 익명 ID U29-001부터 부여한다. 참여 거절·중단 가능, 실제 이름·연락처 불필요, 얼굴 프레임·PCM·화면 녹화 기본 수집 없음. 별도 동의한 비식별 결과 화면만 보관한다.

첫 배정은 U29-001 파츠, U29-002 한 장, U29-003 분리 그림, 이후 같은 순서다. 개발자가 옆에서 관찰하되 다음 버튼을 알려주거나 클릭하지 않는다. 공개된 앱 도움말은 자력 사용으로 허용한다. 요청받아 힌트를 주거나 대리 조작하면 시각·이유·범위와 해당 과제를 assisted로 남긴다. 장치 설치 지원도 예외로 숨기지 않는다. 참여자가 중단하거나 60분에 도달하면 실패/미완료와 이유를 기록한다. 한 과제의 실패도 분모에서 빼지 않는다.

## 동일한 과제 카드

1. 새 시험 폴더의 ZIP을 풀고 앱을 실행한다. 개발 도구 설치나 보호 기능 해제를 요구하지 않는다.
2. 배정 경로에서 캐릭터를 새로 만든다. 파츠는 내장 기본 조합, 한 장/분리 그림은 권한 있는 제공 샘플 또는 본인 자료를 사용한다. 자료의 출처·형식·해시만 기록하고 개인 경로는 기록하지 않는다.
3. 눈·입·고개를 실제 움직여 확인하고 한 군데 이상 모양/역할/색을 원하는 대로 보정한다. 의도한 결과와 자동 결과 제시 여부를 적는다.
4. 프로젝트 저장·닫기·재열기로 동일한 모습과 편집 상태를 확인한다.
5. 실행 창에서 장치 없이 움직임을 확인하고, 동의한 경우 웹캠·마이크를 각각 직접 연결한다. ‘연결됨’과 ‘얼굴 검출/음성 반응 성공’을 구분한다.
6. OBS 33.0.1의 브라우저 소스에 연결해 캐릭터·투명도·움직임·표정·작업 UI 제외를 확인한다. 실제 송출은 하지 않는다.
7. 독립 INP를 생성하고 앱을 종료한 상태에서 Inochi Session 0.8.7로 열어 움직임·표정을 확인한다. PNG 저장은 이 성공을 대신하지 않는다.
8. 다른 두 경로를 별도 프로젝트로 수행한다. 첫 경로와 이후 경로의 시간/성공률을 섞지 않는다.

## 기록과 판정

경로 선택 시각, 첫 자동 결과 시각, 첫 움직임 시각, 방송 미리보기 확인 시각, 내보내기 요청/완료/독립 구동 시각을 ISO8601(+09:00)로 기록한다. 스톱워치 구간은 wait/active/blocked/pause로 상호 배타적으로 구분하고 합계와 전체 시간을 대조한다. 시스템 대기 중 조작했다면 active로 기록해 중복 합산하지 않는다. 이탈·시간 제한도 종료 시각을 남긴다. 보정 행동 수·고유 부위 수·재분석 횟수·도움말·힌트·대리 조작을 별도로 센다.

성공은 실제 움직임·저장 재현·OBS 수신·앱 종료 후 독립 구동 등 각각의 관찰 사실로 판정한다. 자기보고는 self_report, 관찰자가 실제 본 경우 direct_observation, 동의한 결과물만 받은 경우 consented_artifact, 미확인은 unverified로 남긴다. 원격 채팅 답변을 직접 관찰로 올리지 않는다. 7일 첫 사용/14일 반복 관찰창이 끝나지 않은 사람은 in_progress로 남기고 출시 비율 분자·분모와 분리한다. [기록 양식](../user/observation-template.json)은 빈 값에서 시작한다.

T-284는 실제 참여자의 막힘→변경 ID→새 빌드→같은 과제 재관찰을 연결해야 완료다. 개발자 회귀 성공만으로 닫지 않는다. 현재 알려진 INT27-CAM01, 2시간 실행, 깨끗한 OS, 출시 표본과 성능 게이트는 별도 미해결이다. 시험 배포 전 권리·품질·서명·지원 담당을 검토하며 이번 로컬 작업은 배포하지 않는다.
