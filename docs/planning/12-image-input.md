## 사용 방법

1. 새 프로젝트의 **자료 준비 → 그림 파일 선택**을 누른다. 한 장 그림을 작업실에 놓아도 같은 검사로 들어간다. 분리 PNG 여러 장이나 묶음을 한 장 그림으로 오인하지 않도록 한 파일만 받는다. PSD/PSB 직접 읽기는 초기 제외이며 PNG 폴더/.2dparts의 구조 가져오기는 분리 제작 단계에서 연결한다.
2. 읽기가 성공해도 아직 프로젝트 내용은 바뀌지 않는다. 후보 번호를 선택하거나 노란 영역을 직접 지정한다. 복수/미확인 대상은 “캐릭터 한 명”을 확인해야 한다. 얼굴 기준 제안이 몸 전체 경계를 정확히 찾았다는 뜻은 아니다.
3. 영역/지우기/복원 도구를 선택해 드래그하거나 좌표를 입력한다. 마스크 도구는 **현재 좌표에 마스크 추가**로 키보드에서도 사용할 수 있다. 배경 허용값은 0~80이며 결과는 실제 적용된 PNG 미리보기에서 확인한다. 복잡한 배경을 완전 자동 분리한다고 표시하지 않는다.
4. **선택 영역 분석·적용**은 얼굴/제한 확인과 정적 원화 연결까지 수행한다. 경로별 눈·입 추출/분리·움직임 리깅은 후속이다. 변경 전에 복구 지점을 만들고, 성공한 내용만 편집·저장에 포함한다. 취소·실패·새 편집/프로젝트 전환은 기존 작업을 보존한다.
5. 다른 그림을 선택하거나 영역을 다시 적용하면 이전 분석·움직임 연결을 지우고 새 정적 그림으로 전환한다. 되돌리기로 이전 연결을 복원할 수 있다. 범위 밖 입력에는 다시 저장한 PNG/JPEG 사본이나 다른 제작 경로/고급 예제를 안내한다.

실패 후 재시도는 파일이 다시 저장되었을 가능성을 고려해 **전체 읽기/검사부터 다시 수행**한다. 취소한 결과나 이전 파일의 부분 분석을 재사용하지 않는다. 영역 적용 실패의 재시도는 확인했던 동일 정리 사본과 선택을 다시 처리한다.

프로젝트 1.2의 `inputPreparation`은 자원 참조·선택·마스크·전처리·분석 보고를 저장한다. 1.0/1.1도 열 수 있으며 업그레이드한 프로젝트는 다른 파일로 저장해 이전 원본을 보호한다. 입력의 원본 바이트는 자급 ZIP 안에 보존한다. **원본 비교 화면**은 EXIF 방향/색상을 정리한 전체 사본을 사용하므로 자르기/배경/마스크 적용 전 구도를 확인할 수 있다. 원시 바이트를 방향 정보와 무관하게 그대로 디코드했다고 표시하지 않는다.

## 해석과 제한

자동 제안은 전경 연결 영역과 얼굴 후보의 휴리스틱이다. 겹친 인물·얼굴을 못 찾는 그림·복잡한 배경은 직접 영역/마스크로 보정한다. 가림 여부는 확정 분류 모델이 아니라 얼굴 미확인 경고와 사용자 신고로 기록한다. 가장자리 경고는 실제 신체 잘림 판정이 아니라 알파 접촉 신호이며 배경이 불투명하면 거짓 경고가 가능하다. 마스크로 숨긴 RGB는 중립색에 합성한 뒤 얼굴 분석하므로 지운 대상의 숨은 RGB를 분석하지 않는다.

384MiB는 이미지 작업의 사전 추정 예산이며 Python/MediaPipe 기본 런타임까지 포함한 OS 메모리 상한 측정이 아니다. 프로세스당 60초 제한과 한 입력 작업 제어를 사용한다. 큰 그림의 현재 편집 미리보기는 축소 사본을 사용하며 원본 고해상도 재합성·출력은 후속이다. 기본 예제 PNG는 바꾸지 않았다.

검증은 실제 로컬 파일/프로세스와 프로그램 방식 UI·선택 대화상자 adapter를 사용한다. 사람이 Windows 파일 선택/드롭을 직접 조작한 관찰, 전체 DPI/접근성/화풍 품질, 새 Windows, 호스팅 CI, 실시간 장치·새 OBS·외부 프로그램·M0 FPS/장시간 합격은 주장하지 않는다. **M0 HOLD·5개 OPEN·T-121~410 미완료**, T-268/271 전체 통합/현실 실패 검증을 유지한다.
