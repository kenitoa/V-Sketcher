# 18. 표정 저장·전환·제어 우선순위

2026-11-17 · 앱 0.13.0 · 공통 모델 1.8 · T-171~180.

## 사용

세 제작 경로에서 캐릭터를 준비한 뒤 **표정·입력 제어**를 연다. 고급 원화 미리보기 옆에서 **새 표정 → 이름 → 저장할 항목/값/고정 → 표정 만들기**를 사용한다. 기본 자세·눈 감기·미소용 눈/입은 수치 초안이며 원래 그림에 없는 표정을 복원하는 기능은 아니다. 부위가 연결되어 있어야 사용할 수 있다.

**고정**한 항목은 실시간 입력보다 우선한다. 고정하지 않은 항목은 입력이 없을 때의 표정 기본값이다. 다른 부위의 카메라/마이크 입력은 계속 유지한다. 적용은 미리보기만 바꾸며 저장값을 덮어쓰지 않는다. 현재 자세를 저장하려면 체크한 범위의 **현재 값 가져오기 → 값 확인 → 저장**을 사용한다.

전환/해제 시간을 0~3000ms로 고른다. 0은 즉시다. **표정 해제**는 선택한 동작에 따라 최신 입력으로 잇거나 해당 항목을 중립으로 유지한다. **입력 다시 받기**는 중립 유지도 해제한다. **편집 시험 해제**는 슬라이더/재생 소유권만 해제한다. 표정 복제/삭제·정책 변경·수선은 되돌릴 수 있다.

입 입력 우선 모드와 다른 입 입력으로의 대체 허용을 선택한다. 신호를 합산하지 않으며 300ms 동안 유효한 우선 입력이 없을 때만 대체한다. 자동 깜빡임은 기본 꺼짐이다. 합성 카메라/마이크와 **입력 중단**으로 우선순위와 유효 시간 만료를 시험할 수 있다. 실제 웹캠/마이크를 열지 않는다.

정책에서 앱 안 단축키 1~3 슬롯을 지정한다. `Ctrl+Alt+Shift+1~3` 적용, `...+0` 해제이며 대화상자를 닫은 편집 화면에서만 실행한다. 글/한글 조합/선택 입력과 모달에서는 실행하지 않는다. 버튼은 같은 동작을 제공한다.

부위 삭제·새 구조 적용으로 대상이 달라진 표정에는 **연결 확인 필요**가 표시된다. 정상 값은 유지된다. 손상된 값을 선택해 현재 부위에 다시 연결하거나 제거한다. 새 부위에 자동으로 재연결하지 않는다. 한 장 그림 교체/재분석도 저장 표정/매개변수/정책을 보존한다. 전체 예제 재삽입은 명시적 교체 명령이며 복구 지점/되돌리기를 제공한다.

## M2 종료 검토와 다음 범위

**M2 로컬 제작 흐름 검토 통과.** 파츠·한 장·분리 그림이 동일한 프로젝트에서 외형/보정·세부 편집·표정·움직임 시험·원자적 저장으로 합류한다. 세 경로의 표정 소유권/잡음 비저장/해제/손상 수선/파일 왕복 누락을 해결했다. M3의 19~20단계 실제 장치 결합 구현으로 진행할 수 있다. 기존 17단계 검사는 당시의 제작 기반 점검 기록으로 보존한다.

**M0는 HOLD이며 5개 재검증은 OPEN**이다. 이 검토는 고정/합성 입력의 로컬 제작 검토다. 실제 카메라/마이크 검출·보정/평활화·장치 상실, OBS/방송 성능·지연/장시간, 독립 ART-01·초보자 관찰, 독립 아바타 내보내기/외부 재생, OS 전역 키와 T-268/271 전체 통합은 해당 후속 기준을 실제로 통과해야 한다. 세 제작 경로·고급 원화·앱 안 실행/방송·독립 내보내기와 필수 장기 3D/자체 모델 생성 범위를 유지한다.

재현: `node scripts/verify-expressions.mjs`는 필수 gate와 전체 개발 앱 검사를 실행한다. release 패키지를 만든 뒤 `node scripts/expression-package-check.mjs --evidence-dir=evidence/phase18`, ZIP 생성 후 `python scripts/expression-audit.py`로 결합 근거를 확인한다. 이전 단계의 실험/근거는 수정하지 않는다.
