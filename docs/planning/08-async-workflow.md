## 실제 검증 근거

[검사 보고서](../../evidence/phase08/verification.json): **Node 42개+Python 3개=45개 검사 그룹 통과**. 기존 25개를 포함하고 08에서 Node 20개 그룹을 추가했습니다. TypeScript strict·Ruff·스키마 생성 일치·시험 빌드도 통과했습니다. 하위 반복/경합 사례를 별도 기능 수로 더하지 않습니다.

[개발 앱 실행](../../evidence/phase08/development-run.json)과 [보류 결과 화면](../../evidence/phase08/review-ui.png): 실제 Electron renderer에서 고정 작업을 시작하고 처리 중 수동 보정→완료→비교→안전한 항목 적용→새 작업 취소를 실행했습니다. 수동 보정이 유지되고 소유 자원 수가 0으로 돌아오는지 확인했습니다. 기본 캐릭터의 실행 스냅샷과 07 GPU 이동/crop 검사도 유지했습니다. 앱 소유 DOM/self-check와 capturePage의 자동 시험이며 사람이 전체 제작 과제를 완료한 관찰은 아닙니다.

[배포 실행 1](../../evidence/phase08/packaged-run-1.json), [실행 2](../../evidence/phase08/packaged-run-2.json), [패키지 감사](../../evidence/phase08/package-audit.json): 고급 화면·작업 상태 핵심·번들 worker/모델·정상 종료를 확인하고 release에서 상태 시험 버튼이 없는지 검사했습니다. [배포 화면](../../evidence/phase08/release-studio.png)을 검수했습니다. 이전에 합의한 동일 PC의 개발 도구 PATH 제거·새 프로필·한글/공백 경로 범위이며 새 Windows 검증은 아닙니다. 카메라/마이크/OBS는 사용하지 않았습니다.

[최종 감사](../../evidence/phase08/audit.json)와 [산출물 manifest](../../evidence/phase08/artifact-manifest.json)는 410개 Todo 중 첫 80개 완료, 52개 기능·12개 PD·15개 AC 보존, 과거 02~07 근거 불변, 코드/보고서/패키지 해시를 확인합니다. CI는 동일 명령으로 갱신했고 호스팅 실행은 하지 않았습니다. ZIP은 `out/make/zip/win32/x64/2DSketcher-win32-x64-0.3.0.zip`, 실행 파일은 `out/2DSketcher-win32-x64/2DSketcher.exe`입니다.

## 정책 상세화와 후속 연결

T-076/077과 Function 3.2/4.2의 요구에 맞춰, 05의 “stale 폐기”를 **자동 적용 차단 및 AWAITING_REVIEW 보관**으로 구체화했습니다. 다른 프로젝트/세대·취소/중복 응답 거부는 유지합니다. 이전 정책 실험과 ResultGate 검사는 당시 범위의 역사로 남기고 새 준비 작업은 Workflow를 사용합니다.

이번 저장/내보내기 성공은 **모의 어댑터 receipt에 대한 상태 규칙 시험**입니다. 디스크 파일이나 외부 결과가 실제로 생성됐다고 주장하지 않습니다. 임시 파일은 소유권 정리 검증용이며 분석 결과 자산의 영구 승격/안전 교체는 아직 없습니다. 비협조적 작업은 종료한 것처럼 표시하지 않고 지원 경계/프로세스 종료를 기다립니다. 메모리 체크포인트는 영구 복구·undo가 아닙니다.

T-268에서 실제 제작/분석·저장·출력 어댑터를 연결한 취소/재시도/전환/지연 응답을 다시 검증하고, T-271에서 실제 저장 중 공간 부족·권한·경로 오류와 마지막 정상본 보존을 확인합니다. T-081 이후 프로젝트 생성/저장 UI와 후속 제작·추적·OBS·외부 구동·성능·초보자 검증은 미완료입니다. 08 완료가 M1 또는 출시 합격을 뜻하지 않습니다.
