# 26. 환경 설정·개인정보·성능 조절·지원 정보

2026-11-18 · 앱 0.21.0 · 모델 1.9 유지 · T-251~260 구현·검증 중.

왼쪽 **환경 설정**에서 장치·저장·키, 개인정보, 성능·품질, 지원 정보를 연다. 프로젝트 설정과 이 PC의 설정을 구분한다. 소개 문구를 추가하지 않고 실제 조작·처리/보관 경계·계측·지원 범위를 표시한다. [구현 계약](../architecture/environment.md).

기본 폴더와 복구 주기, 기본 장치, 기기별 빠른 키를 관리한다. 장치 허용은 자동 연결이 아니며 현재 카메라/마이크 해제는 에디터와 실행본의 실제 자원을 종료한다. 장치·로컬 진단 기록 허용을 독립적으로 관리하며 서버 진단 전송/학습 활용은 현재 제공하지 않는다. 기존 로그 삭제·앱 데이터 위치·수동 파일/복구본 삭제 절차를 안내한다.

성능 화면은 최근 실행 제출 FPS/CPU 제출 p95, 구간/표본, Electron CPU/작업 집합, 텍스처 기본 레벨 추정을 구분한다. GPU 완료/센서→OBS 전체 지연/인코더 성능은 미측정이다. 실행 미리보기 FPS/해상도와 방송 출력 설정을 별도로 조절·복원하며 원화와 프로젝트를 보존한다. 자동 품질 조절은 **미제공**으로 결정했다.

진단 파일은 항목을 먼저 확인하고 로컬 JSON으로 저장한다. 원본·영상·음성·개인 경로·장치 식별자·프로젝트 이름·원시 오류/로그·토큰을 포함하지 않는다. 현재 지원 입력/대상/설치된 버전·실제 기준 장비·현재 프로젝트 자산 출처/이용 조건·번들 고지를 제공한다.

## 검증 계획과 M3 종료 검토

필수 `tools\dev.cmd run check`, 신규 설정 12개 및 오디오 시계 회귀 1개 검사, 기존 전체 편집/실행/입력 회귀, 실제 세 경로 방송·PNG/INP 및 설정 UI, 같은 PC 개발 도구 PATH 제외 release 새 프로필 기본/1080×720을 구분한다. 실제 장치 시험은 사용자가 카메라/마이크와 본인 얼굴을 확인한 뒤 시작하며 정면·눈/고개·무음·발화 구간과 종료 후 실제 자원 해제를 기록한다. 영상/원음은 근거 파일로 저장하지 않는다. 별도 OBS는 캐릭터 소스만 캡처하며 사용자 기존 장면·녹화·송출을 변경하지 않는다.

T-260의 종료 검토는 새 근거가 통과한 범위에 따라 기록한다. 합성 입력·페이지 ACK·제출 FPS·사용자 보고를 실제 장치/공식 대상/전체 성능의 자동 통과로 바꾸지 않는다. T-190/T-209, M0 HOLD/5 OPEN, 별도 깨끗한 Windows·장치 호환성·장시간 성능·독립 ART/초보자 표본·필수 장기 기능을 유지한다.

전체 회귀에서 실행 중 오디오 엔진과 UI 시계의 간격이 달라진 뒤 입력이 영구 지연으로 분류되어 표정 해제 후 마이크 복귀가 실패한 기록을 보존했다. 현재 오디오 엔진 시각과 패킷 시각 차이로 신선도를 검사하고 그 차이를 표시 시계로 변환하도록 수정했다. 150ms 이상 오래된 패킷·중복·역행은 계속 거부하며, 이 수정은 실제 음성 품질/장치 호환성 승인을 대신하지 않는다.
