## 사용 방법

같은 프로젝트에서 **세부 부위·연결·변형**을 누른다. 목록/중앙 그림/세부 화면의 선택은 같은 부위 ID를 사용한다. 돌아갈 때 선택과 적용한 내용이 남는다. 소개 헤드라인이나 슬로건은 추가하지 않았다.

부위의 이름·역할·캐릭터 좌우·화면 그룹·움직임 부모·순서·위치·불투명도를 조절하고 **부위 변경 비교**를 누른다. 그룹 생성/이름/부모/표시/alpha도 별도 후보로 확인한다. 부모 변경은 보이는 위치를 유지하고 새 부모 기준 좌표로 바꾼다. 순환·없는 참조는 적용되지 않는다.

망의 금색 기준점과 점을 확대/드래그하거나 로컬 px 수치를 수정한다. 점의 기울기 가중치·좌우 최소/최대 변위, 고개 축 연결과 곡선을 바꿀 수 있다. **이 부위 영향 범위 다시 지정**은 원 안의 가중치/변위를 새로 만드는 명시적 작업이다. 허용 범위와 극단 격자의 접힘 검사를 통과해야 한다.

기존 매개변수와 부위의 변형/저작된 상태 연결을 추가·수정·해제한다. 같은 축의 중복, 없는 상태·매개변수와 범위 초과는 차단한다. 새 PNG는 한 상태의 교체 후보로 준비되며 원본과 다른 표정을 보존한다. 삭제는 자식·연결·표정·입력·외부 변환 영향을 먼저 보고한다.

현재 결과와 새 후보에서 **최소·중립·최대**를 비교한 뒤 **비교한 변경 적용**을 누른다. 입력을 바꾸면 다시 준비해야 한다. 망/구조/연결/그림/전체를 부위별로 복원할 수 있고, 그룹은 별도로 복원한다. 삭제한 부위만 남거나 부위가 전혀 없어도 복원 목록을 연다. 부모가 삭제된 경우 부모부터 복원한다.

간단 제작이 세부 구조를 다시 만들려 하면 수동 조정을 유지하고 영향을 안내한다. 필요한 부위·그룹을 복원하거나 사본에서 계속한다. 오류·후속 검사 위치는 부위/매개변수/연결/그룹 ID 또는 망 점 번호로 연다. 오래된 참조는 현재 목록으로 복구하며 원본과 선택을 보존한다. [상세 데이터·적용·보관 계약](../architecture/detail-editor.md).

## 검사와 범위

`tools\dev.cmd run check`는 기존 포함 Node 167·Python 31, 총 **198개 검사 그룹**을 실행한다. 새 세부 편집 검사는 Node 20개 묶음이다. 전체 개발 앱 회귀와 세 경로의 실제 세부 화면, 기본/1080×720 동일 PC release 두 번의 **세부 편집+기반 코어**를 검증한다. 패키지의 이전 기능 UI는 NOT_RUN이며 전체 개발 앱에서 따로 확인한다. 개발 도구 PATH를 제거한 새 프로필을 사용하며 새 Windows 설치라고 주장하지 않는다.

공통 GPU에서 세 경로의 기준점 수정 전후 고개 최소/중립/최대 12프레임씩을 비교한다. 중립 평균 오차 <0.02/255, 극단의 실제 변경, GL 오류 0과 버퍼 재업로드 없음이 기준이다. 다른 부위의 망·자원·표정/입력/설정 보존도 확인한다. [전체 검사](../../evidence/phase17/verification.json) · [개발 앱](../../evidence/phase17/development-run.json) · [세부 화면](../../evidence/phase17/detail-ui.png) · [세 경로 비교](../../evidence/phase17/detail-extremes.png) · [패키지](../../evidence/phase17/package-audit.json) · [감사](../../evidence/phase17/audit.json).

실측 중립 평균 차이는 세 경로 모두 0이며 극단 변경 채널은 각각 4,076 / 95,074 / 2,723이다. `scripts/detail-preservation-check.mjs`의 [추가 검사](../../evidence/phase17/preservation.json)는 실제 UI 저장본에 비어 있지 않은 비대칭/잠금 표정·입력/fallback·외부 매핑과 다른 세기/평활화/자세를 넣어 세부 수정·부분 복원·자급 저장 왕복에서 보존을 확인한다. 외부 매핑은 미검증 상태로 남으며 실제 변환 승인으로 해석하지 않는다.

사람의 초보자/숙련자 관찰·독립 ART-01·전 구간 동적 품질·전체 자유 topology 생성·3D 회전·표정 제어 우선순위·실제 추적/방송/독립 INP 변환은 후속이다. M2 종료는 T-180, 전체 통합은 T-268/271에서 확인한다. 이전 experiments 02~05와 evidence 06~16은 동결 보존한다.
