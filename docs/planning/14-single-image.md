## 사용 방법

**그림 한 장** 프로젝트를 만들고 **그림 파일 선택**에서 PNG/JPEG를 가져온다. 캐릭터 한 명의 전체 영역·배경/가림을 확인해 **선택 영역 분석·적용**을 누른다. 이 단계는 원화 준비이며 자동 리깅 완료로 표시하지 않는다.

**눈·입과 제한 고개 자동 준비**를 누른다. 얼굴이 먼저 준비되면 작은 고개를 시험할 수 있고, 최종 결과에서는 확인된 눈·입만 움직인다. 원본 그림과 자동 결과를 비교하고 **비교한 자동 결과 적용**을 누른 뒤 **적용한 결과의 움직임 시험**으로 간다. 적용 전에는 현재 정상 구조/원본/저장 파일이 그대로다.

다른 표정 상태는 원화에서 보이지 않는 표현의 추정이다. **추정 표정 없이 원화·작은 고개만 준비**로 대체하거나 **이 결과 폐기**로 돌아간다. 결과 준비 중 취소·실패·현재 편집/대상 변경은 최신 프로젝트를 덮어쓰지 않는다. 실패는 원인 확인 후 명시적으로 재시도한다. 얼굴이 없거나 여러 개면 정면 얼굴·대상 선택을 다시 확인한다. 눈·입/가림의 세부 위치·경계 보정 및 부분 재분석은 15단계에서 구현한다.

적용은 하나의 편집 이력이며 변경 전 영구 복구본을 남긴다. 원본과 이전 자산을 보존하고 `.2dsketch` 자급 ZIP에 원본/추정 자산·좌표·표정/망·버전/제한을 함께 저장한다. 복제는 새 프로젝트의 입력 리비전 0으로 재기준화한다. 이전 모델 1.0~1.3은 보호 변환하며 새 minor는 읽기 전용이다.

## 품질 해석·지원 제한

한 장 자동 구조화는 원화 기반 국소 표정과 작은 평면 변형의 초기 구현이다. 완전한 의미별 머리카락/몸통 분리·가려진 원래 표정 복원·큰 회전·새로운 측후면·독립 물리 움직임을 제공하지 않는다. 고급 입력 3개의 중립 원화 세부는 픽셀로 보존하나 추정 눈꺼풀/입 안의 자연스러움은 원본 복원 품질과 다르다. 복잡한 가닥 가림/희미한 표정/폐안·옆모습/비인간형에서 검출과 국소 보완 편차가 있으며 확인되지 않은 연결은 제공하지 않는다. 범위를 좁혀 실패 표본을 분모에서 빼지 않는다.

실제 GPU의 텍스처 보간/경계 래스터 차이는 CPU 픽셀 재조합과 구분해 측정한다. 512×512 중립 GPU 비교의 채널 평균 차이는 약 0.0504/255, alpha 평균 차이는 약 0.0531/255이며 경계의 최대 채널 차이는 97/255다. 사각 패치 경계의 미세한 샘플링 차이를 GPU 픽셀 동일성으로 숨기지 않는다. 25개 GPU 상태와 눈/입 50% 상태의 내부 alpha 손실 0은 확인했지만 원화의 모든 동적 자연스러움을 보증하지 않는다. 고급 원화 동적 ART-01 평가자 3명·초보자 완주·M0 성능/장시간/방송·외부 표현 동등성·출시 지원 범위 승인·새 Windows·호스팅 CI는 후속이다. **M0 HOLD·5개 OPEN·T-141~410 미완료와 T-268/271 전체 통합 검증을 유지**한다.
