## 사용 흐름

시작에서 경로를 고르고 초안을 만든다. **자료 준비 → 고급 예제 넣기**로 현재 지원하는 편집을 사용할 수 있다. 예제는 준비된 고급 원화이며 자동 분리/리깅이 아니다. **외형 편집**에서 그림이나 왼쪽 목록으로 부위를 선택한다. 이름은 Enter 또는 입력칸 이탈로 적용한다. 부위 역할·불투명도·가로 위치·저장된 표정 값 편집은 기존 보존/되돌리기 체계를 따른다.

**외형 확인 완료**는 사용자의 확인 표시다. **저장 전 확인 → 그림 파일 확인**은 실제 프로필 캐시 파일의 해시/크기를 확인하며, 현재 편집의 리깅·움직임·장치·방송·외부 형식 호환을 합격시키는 검사가 아니다. 실패/취소 후 현재 편집을 유지하고 다시 시도할 수 있다. 다른 단계로 이동해도 같은 프로젝트를 사용한다.

미리보기의 배율 100%는 전체 맞춤 기준이다. 휠·＋/−로 확대하고 **화면 이동** 또는 Space/가운데 버튼 드래그로 이동한다. `0`은 전체 맞춤, 방향키는 부위 선택, `Shift+방향키`는 화면 이동이다. 원본 비교 중에는 부위 선택을 적용하지 않는다. 배경·가이드·선택선은 작업 편의 설정이며 저장된 캐릭터/방송 배경을 바꾸지 않는다.

오류 안내의 행동 버튼으로 해당 설정에 이동하거나 다른 저장 위치/파일을 고른다. 자세한 코드는 필요할 때 펼친다. **도움말**은 로컬에서 제공하며 네트워크가 필요 없다.

## 제한

직접 클릭/키보드 검사는 앱 소유 DOM 이벤트와 실제 GPU·IPC·파일을 사용한 자동 검사다. Windows 파일 대화상자는 self-check adapter를 사용한다. 사람의 초보자 과제·스크린리더·모든 DPI/해상도·전체 접근성 인증·새 Windows/별도 PC·호스팅 CI 시험은 수행하지 않았다. 현재 PC/드라이버를 유지한 검증이다.

실제 입력 가져오기·자동 제작·세부 변형/움직임 평가·추적·방송·외부 내보내기는 후속 구현이다. 이 단계의 보기 조작이나 파일 확인으로 T-101 이후나 M0 성능/초보자/전체 통합 기준을 완료 처리하지 않는다. 기존 M0 HOLD와 5개 OPEN, 물리적 전원 상실/실제 디스크 고갈 등 T-268/271의 전체 통합·현실 실패 검증을 유지한다.
