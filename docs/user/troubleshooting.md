# 제품 화면으로 문제 확인하기

0.22.0 앱의 **도움말**에서 `OBS`, `복구`, `카메라`, `내보내기`로 검색한다. 같은 내용의 오프라인 `resources/release/USER-GUIDE.md`를 패키지에 포함한다. 개발자 도구나 터미널은 필요하지 않다.

| 증상 | 앱에서 확인할 화면과 순서 | 확인할 결과 / 한계 |
|---|---|---|
| OBS가 비어 있음 | 실행 준비 → 방송 출력 → 출력 준비 → 연결 주소 복사 → OBS 33.0.1 브라우저 소스 URL·크기 입력 | 앱 UI가 빠지고 투명 배경·움직임·표정이 보여야 함. 실제 공개 송출은 이 시험에 포함하지 않음 |
| INP가 안 열림 | 이미지 저장·외부 대상 → 외부 아바타 대상·사전검사 → 현재 리비전 검사 → 경고 확인·비교 → 독립 캐릭터 내보내기 | Inochi Session 0.8.7에서 직접 로드. 앱 종료 후 움직임·표정을 확인. PNG와 .2dsketch는 대체 결과가 아님 |
| 저장/복구 | 저장 공간·쓰기 권한 확인 → 사본 저장 → 다시 실행 → 복구본 → 원본/복구 비교 | 복구 전에 원본 삭제 금지. 서로 다른 이름으로 저장 후 재열기. 자동 복구가 모든 물리적 디스크 장애를 보장하지 않음 |
| 얼굴이 보여도 안 움직임 | 카메라 입력 → 장치 선택·연결 → 미리보기와 검출 인원 각각 확인 → 조명·정면 자세 재확인 | 연결 성공과 검출 성공 분리. INT27-CAM01(미리보기 정상/0명)은 조사 중. 해결된 것으로 표시하지 않음 |
| 입이 안 움직임 | 마이크 입력 → 장치·입력 음량·헤드셋 음소거 확인 → 해제/재연결 | 실제 발화 반응을 확인. 연결 상태만 성공으로 세지 않음 |
| 느리거나 멈춤 | 환경 설정 → 성능에서 구간 값 확인 → 해상도·FPS 낮춰 비교 → 장치 해제 후 수동 시험 | 화면 제출 FPS는 입력→방송 전체 지연이 아님. 2시간 연속·기준 성능 승인 전 |

제품 화면: [첫 안내](../../evidence/phase29/run-05/package/packaged-ui/guide-start.png), [방송](../../evidence/phase29/run-05/package/packaged-ui/guide-broadcast.png), [내보내기](../../evidence/phase29/run-05/package/packaged-ui/guide-save.png), [복구](../../evidence/phase29/run-05/package/packaged-ui/guide-recovery.png), [장치](../../evidence/phase29/run-05/package/packaged-ui/guide-devices.png). 이 이미지는 자동 점검 화면이며 초보자 관찰 사진이 아니다. 수정 후 최종 패키지 화면도 29단계 증거에 별도 보관한다.

해결되지 않으면 [피드백 양식](feedback.md)에 버전·환경·단계·화면의 오류 코드를 적어 이번 시험 담당자에게 전달한다. 개인 경로·로컬 방송 주소·원본 오류·얼굴·음성·인증정보를 넣지 않는다. 공개 문의 창구와 자동 전송은 제공하지 않는다.

실제 대상 화면 근거: [앱 방송 출력 패널](../../evidence/phase27/run-1794981764746/broadcast/broadcast-ui.png), [OBS 수신 움직임](../../evidence/phase27/run-1794981764746/obs-03/parts-motion.png), [외부 실행기 입 벌리기](../../evidence/phase27/run-1794981764746/external-02/parts-v1-mouth-open.png). 27단계의 실제 대상 확인을 재사용하며 이번 안내 점검을 새 OBS/외부 실행 성공으로 표시하지 않는다.
