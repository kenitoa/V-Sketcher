# Windows 포터블 설치와 자료 보존

현재 0.22.0 로컬 시험판은 ZIP 전체 압축 해제 방식이다. 설치형·자동 업데이트·등록된 제거 프로그램은 없다. 관리자 실행, Node.js/Python 별도 설치, OS 보호 기능 해제는 요구하지 않는다. 동봉된 worker·모델·Electron과 resources 전체가 필요하므로 EXE만 옮기지 않는다.

1. 쓰기 가능한 새 앱 폴더에 ZIP 전체를 푼다. 프로젝트·원본 그림은 앱 폴더 밖의 별도 작업 폴더에 둔다.
2. `2DSketcher.exe`를 실행하고 앱 정보에서 0.22.0을 확인한다. 홈의 첫 사용 안내와 예제로 장치 없이 시작한다.
3. 업데이트 전 프로젝트를 저장하고 별도 백업한다. 앱을 종료한 뒤 새 ZIP을 **다른 버전 폴더**에 푼다. 기존 버전에 덮어쓰거나 사용자 자료를 이동·삭제하지 않는다.
4. 새 버전에서 프로젝트 **사본**을 열어 원화·부위·움직임·저장을 확인한다. 이전 앱 폴더와 변경 전 원본은 검증이 끝날 때까지 보관한다. 문제가 있으면 이전 EXE와 이전 원본 백업으로 돌아간다. 이전 앱이 새 형식 파일을 읽는 것은 보장하지 않는다.
5. 제거는 앱을 종료하고 압축을 풀었던 앱 폴더만 지우는 방식이다. 폴더 안에 사용자가 넣은 자료가 있다면 먼저 밖으로 옮긴다. 프로젝트와 원본 자산, 앱의 사용자 데이터(설정·복구본·캐시)는 자동으로 지우지 않는다. 환경 설정 → 앱 데이터 폴더에서 위치를 확인할 수 있다. 복구 여부를 확인하기 전 이 폴더를 지우지 않는다.

검증 PC는 Windows 11 Pro 10.0.26300 x64, i5-13420H, RAM 31.71GiB, RTX 4050 Laptop 6GB + Intel UHD다. WebGL2와 쓰기 가능한 저장 공간이 필요하며 카메라·마이크는 입력 연결 시에만 필요하다. 최소 CPU/RAM/GPU 수치, 다른 Windows 빌드, 낮은 사양·내장 GPU 단독, ARM64·Windows 10·macOS/Linux·VM은 보증하지 않는다. 개발 PC의 새 프로필/개발 도구 PATH 제거 시험은 깨끗한 새 Windows 시험을 대신하지 않는다.

서명되지 않은 로컬 시험판이다. 보안 경고가 나타나면 출처를 확인하고 중단할 수 있으며 보호 기능을 끄지 않는다. 공개 배포는 승인되지 않았다. 방송은 OBS Studio 33.0.1, 독립 INP는 Inochi Session 0.8.7(SDK 0.8.6)로 실제 시험했으며 두 프로그램은 동봉하지 않는다. 로컬 업데이트·제거 검증 도구는 개발 검사용이고 사용자 시스템의 설치를 자동 관리하지 않는다.
