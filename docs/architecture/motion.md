# 공통 움직임 모델과 평가

프로젝트 모델 1.1의 선택적 `motion`은 부위 로컬 삼각망(정점·index)·기준점·영향 가중치·최소/최대 변위·linear/smoothstep 곡선·고개 제어 참조와 세기/평활화/저장 자세를 담는다. 1.0도 읽고 편집할 수 있지만 새 움직임 데이터를 추가하면 복구 지점을 만든 뒤 1.1 변환본을 다른 파일에 저장한다. 변환 전 원본 위치로 저장하는 요청은 차단한다. undo가 모델 버전을 자동 다운그레이드하지는 않는다.

모델은 부위/매개변수 참조, 삼각형 index·winding·면적, 가중치/유한 범위·변위 한도·저장 자세를 검증한다. 좌우/기울기 극단 조합에서 뒤집히거나 거의 붕괴하는 망은 거부한다. 이전 버전/복제·저장/복구/undo는 같은 모델 검증을 사용한다. 원본 PNG나 개인 장치 식별자를 수정/추가하지 않는다.

## GPU 경로

`projectToPreview`는 원본/편집/부위/부모 좌표를 공통 project 좌표로 바꾼다. 파츠의 정적 삼각망 위치/UV/가중치/최소/최대 변위는 texture별 buffer에 한 번 업로드한다. frame마다 정규화한 제어와 행렬/회전/불투명도 uniform만 갱신한다. CPU raster 변형→PNG 인코딩은 사용하지 않는다.

vertex shader는 부위와 부모 transform binding → 가중치가 적용된 기준점 회전 → 곡선으로 보간한 좌우 변위를 평가한다. 정상 기울기 최대 6°, 좌우 최대 기준 얼굴 폭의 4.5%, 하단 몸체 가중치 0을 적용한다. 가림 제안은 0.35 배율이다. 준비된 눈/입 그림은 연속 smoothstep 가중치로 합성하고 각 자원의 crop 밖 fragment를 버린다. 부위마다 임계값 하나로 눈을 스위칭하지 않는다.

선택은 동일한 변형 수식의 CPU 참조와 deformed triangle의 barycentric UV·실제 텍스처 알파를 사용한다. 선택선도 평가된 경계를 따른다. 원본 비교는 시험을 멈추고 별도의 원본 scene을 표시한다. scene의 기본 제어는 저장 자세로 생성하므로 복구 비교·정적 미리보기에도 같은 기준 자세가 적용된다.

## 장치 없는 입력

`MotionPlayer`는 카메라/마이크·타이머·파일·프로젝트 편집을 소유하지 않는 평가기다. 외부 표시 시각을 받아 입력 검사/clamp → 지원 동작 제한 → 저장 자세 기준 세기 → 시간 기반 지수 평활화 → 공통 다섯 제어 정규화를 수행한다. 음수 dt는 0, 긴 dt는 100ms로 제한한다. 모델/세션 전환·설정 변경·중지는 시간/평활화 상태를 초기화해 저장 자세로 복귀한다.

4초 단일 동작은 최소·기본·최대·기본을 순회하고 한 번 또는 반복한다. 복합 예제는 좌우 눈의 위상·입·고개를 함께 시험한다. 예제 시간은 표시 frame의 유효 dt 누적이다. 저장된 시험 목표값을 기본 자세로 만드는 명시적 명령만 이력과 파일을 바꾼다. 장치 프레임이나 시험 재생마다 IPC/편집 이력을 만들지 않는다.

지원 여부는 실제 표시 부위와 상태/transform/mesh 연결에서 산출한다. 이름만 있는 제어, 없는 부위, 미지원 custom 제어는 작동 중으로 표시하지 않는다. 보완 그림 기반 입의 시험 상한은 0.65이며 준비된 부위는 검증 범위 내 전체 값을 쓴다. 보조 물리는 초기 미제공으로 결정했다. [결정·검증 범위](../planning/11-common-motion.md)를 따른다.
