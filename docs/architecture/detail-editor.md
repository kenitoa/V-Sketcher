# 세부 부위·연결·변형 편집 계약

앱 0.12.0·공통 모델 1.7의 편집 계약이다. 세 제작 경로가 같은 Project/CharacterPart/MotionMesh/PartBinding을 편집하며 다른 프로젝트로 변환하지 않는다. 기존 삼각망/가중치/변위/곡선과 공통 GPU를 사용한다. 새 망 생성 알고리즘·3D 회전·표정 제어 우선순위·장치·방송·INP 변환의 완료를 뜻하지 않는다.

## 편집과 적용

`DetailOperation`은 부위 속성, 그룹, 망 기준점/고개 축, 점 하나, 원형 영향 재지정, 연결 추가/수정/해제, 그림 상태 하나 교체, 삭제, 선택 범위 복원이다. 이름은 표시 변경이며 역할·좌우·부모·그룹·순서·표시/alpha는 구조/동작/출력 영향을 보고한다. 부모 변경과 삭제 시 직접 자식을 재배치할 때 현재 world affine을 유지한다. 부모를 바꾸는 후보에서는 기존 위치 수치로 새 부모의 local 좌표를 덮어쓰지 않는다. 새 부모를 적용한 뒤 위치를 다시 조절한다.

망은 기존 topology를 유지하면서 점 위치·기울기 가중치·좌우 최소/최대 벡터를 조절한다. 기준점과 위치·변위는 부위 로컬 px다. 원형 영향은 중심/반경/세기를 이용한 smoothstep 감쇠로 가중치와 ±yawDelta의 가로 변위를 명시적으로 다시 지정한다. 원 밖은 0이다. 반경 재지정은 저작된 기존 벡터를 바꾸므로 별도 후보/영향 안내를 거친다. 없는 망은 선택 부위에만 기존 기본 망을 준비한다.

정적 참조/순환·중복 연결·실제 텍스처 상태·변위의 world 길이를 검사한다. 최대 yaw 변위는 faceWidth의 4.5%, roll은 기존 rig의 최대 6° 이내다. 원래/극단 고개의 3×3 격자에서 삼각형의 방향·면적을 검사한다. 접힘·역전·허용 범위 초과는 후보 적용을 차단한다. 중간 전 구간이나 독립 시각 품질 인증으로 확대하지 않는다.

망 고개 축은 현재 GPU 의미인 head_yaw/head_roll에 연결한다. PartBinding은 시험 가능한 다섯 매개변수와 실제 상태 보간 또는 회전 ±6°/이동 ±64px/배율 0.8~1.2를 연결한다. 같은 부위의 상태 연결 또는 같은 변형 축 중복을 허용하지 않는다. 상수 출력은 제어에 따라 움직이는 연결로 표시하지 않으며, yaw는 실제 벡터·roll은 실제 가중치로 사용 가능 여부를 계산한다. 임의 사용자 매개변수의 새 실행 엔진은 후속이다.

## 보관과 복원

`Project.detail`은 처음 세부 수정하기 전의 부위·망·해당 연결과 배열 위치, 구조가 바뀐 그룹을 보관한다. 원본과 과거 텍스처 자원은 지우지 않는다. 기존 분리/자동/파츠 기록은 준비 당시 기록으로 보존한다. 분리 기록에 있는 부위를 삭제한 경우에만 유효한 세부 baseline을 근거로 해당 과거 참조를 허용한다. 현재 실행 모델의 다른 참조 검사와 원본 해시 검사는 유지한다.

복원은 부위 전체, 역할/계층/순서/위치, 망, 연결, 텍스처를 나눈다. 다른 부위·표정/입력/내보내기 프로필을 초기화하지 않는다. 그룹은 별도로 복원한다. 부모가 사라진 부위를 복원하려면 부모부터 복원한다. 부위가 하나도 없는 경우에도 삭제 부위 목록과 후보 적용을 사용할 수 있다. undo/redo는 현재 값과 baseline을 함께 복원하고 `.2dsketch`는 자원과 기록을 함께 저장한다. 구 버전 프로젝트는 새 파일로 업그레이드하며 미래 minor는 읽기 전용이다.

간단 화면의 이름·불투명도 등은 유지한다. 파츠 refresh·전체 입력 교체·자동 구조화/재분석·분리 재안내·기본 망 재생성이 세부 구조를 다시 만드는 경우 `E_DETAIL_PROTECTED`로 차단하고 현재 수동 부위/그룹을 연다. 해당 범위를 세부 화면에서 복원하거나 사본을 사용한다. 작업을 조용히 재실행하거나 세부 조정을 덮어쓰지 않는다. 보관 기록만 생기는 것은 provenance 의존이며 실제 부위·망·연결 변경에 대해서만 기존 세부 의존 키를 무효화한다.

## 영향과 수정 위치

삭제·교체·연결 변경 후보는 부위/자식/매개변수 ID, 참조한 표정·입력·외부 변환 프로필과 끊긴 제어, 재검사 항목을 제공한다. 매개변수 자체와 표정/입력 값은 삭제하지 않는다. 값은 유효하지만 표시할 부위가 없어질 수 있음을 안내한다. 외부 검사 미구현 상태를 호환 성공으로 표시하지 않는다.

`DetailLocation`은 part/parameter/binding/group ID 또는 part ID+vertex index다. DOM selector·파일 경로·표시 이름을 영구 수정 주소로 사용하지 않는다. 현재 Project에서 검증해 위치를 열고, 오래된 ID는 현재 목록 선택으로 복구한다. 실패 시 프로젝트와 직전 선택을 유지한다. 장치/호환 검사의 후속 결과에서도 같은 주소를 사용할 수 있다.

## 비동기·파일 경계

일반 후보는 복제본에서 계산하고 draft ID/revision으로 분리한다. 적용은 checkpoint→문서/세대/revision 재확인→단일 history edit다. 오래된 결과·취소·다른 프로젝트 전환은 현재 작업을 바꾸지 않는다. PNG 교체는 native 선택기의 경로를 main에서만 받고, 제한된 snapshot→독립 PNG worker→원본/정규화 자원 캐시→명시적 후보 적용을 따른다. RGB/RGBA 8bit PNG 1~4096px·64MiB·기존 합산 메모리 한도이며 자동 축소하지 않는다. 선택한 상태만 바꾸고 다른 표정과 part-local 배치/색상 조절은 유지하므로 크기·alpha·이음새를 비교한다. 개인 경로·원시 오류는 일반 로그/renderer에 노출하지 않는다.

분리 경로에서 세부 교체/삭제나 역할 변경을 기존 `.2dparts` 준비 기록으로 정확히 표현할 수 없으면 자료 묶음 저장을 차단한다. 과거 PNG로 되돌아간 결과를 조용히 내보내지 않는다. 현재 편집은 `.2dsketch`로 저장하며, 자료 교환이 필요하면 사본에서 해당 범위를 복원하고 다시 확인한다. 망·연결처럼 원래부터 자료 묶음에 포함하지 않는 동작 정보는 프로젝트 저장을 사용한다.
