# 한 장 그림 자동 구조화

제품 `worker/structure.py`는 가져온 선택 PNG만 읽는다. 고정 로컬 얼굴 랜드마크 모델과 픽셀 대비/alpha/눈 벌어짐·방향 근거로 세 부위 후보를 생성한다. 정답 주석·파일명·이전 수동 패치는 추론 입력이 아니다. 모델 자원은 기존 provision/health의 SHA-256 잠금과 Windows 번들에 포함한다.

`StructureSession`은 기존 `InputSession`과 무거운 작업을 중복 시작하지 않는다. Workflow `preview` 작업의 두 단계는 landmark/visibility → expression/rig다. 이 작업의 출력은 변경 후보의 미리보기이며 `checked` receipt를 사용한다. 준비 작업이 프로젝트를 자동 교체하는 `candidate` 결과로 가장하지 않는다. 실제 적용은 명시적 구조화 적용 명령에서 영구 checkpoint와 리비전/세션/취소 세대 CAS를 재확인하고 하나의 EditHistory 변경으로 수행한다.

조기 미리보기는 선택 원화와 제한 고개만 갖는 별도 Project다. 최종 미리보기는 캐시에 검증한 별도 자산을 참조하며 renderer에는 상대 권한 URL만 전달한다. 취소/오래된 리비전/프로젝트 전환 시 미리보기 접근 권한을 회수한다. 기존 편집·원본·파일은 그대로 유지하며 취소/실패 결과가 늦게 와도 적용할 수 없다.

공통 모델 1.4의 선택 `structure`는 선택 원본 ID·입력 리비전·구성 1.0.0·후보/미확인/판단 근거·추정 상태·영역·제한·적용 모드를 보관한다. 자원 `parentAssetIds`와 `auto-preparation`/`auto-completion` 출처, 텍스처 좌표/부위 변환을 함께 저장한다. 새 입력·파츠/샘플 준비는 이 기록을 삭제하며 undo는 원래 상태로 돌아간다. 복제 시 입력 리비전을 새 프로젝트 0으로 맞춘다.

원본 눈/입 사각 영역은 그대로 별도 상태에 복사한다. base는 그 사각 영역의 alpha 소유권을 패치로 넘겨 반투명 원본을 중복 합성하지 않는다. 추정 패치는 원본 alpha를 유지하고 국소 채움/주변 피부 질감·속눈썹 색/립 변형을 사용한다. 중립 재조합은 원본 RGBA와 동일해야 하며 GPU 샘플링 오차는 별도 기록한다. 숨은 머리·옆면을 복원했다고 표시하지 않는다.

공통 authorRig와 MotionPlayer를 사용한다. 구조화 기록의 고개 배율은 일반 망 재준비에도 적용한다. 확인되지 않은 눈/입은 바인딩이 없고 지원 목록에서 비활성화된다. 제한 대안은 표현 패치 없이 원화+작은 고개만 만든다. 세부 눈·입/경계 보정과 부분 재분석·보정 보호/선택 적용은 [15단계](../Todo)이며 이번 작업으로 완료 처리하지 않는다. [검증/지원 경계](../planning/14-single-image.md)를 따른다.

자동 생성한 눈/입 두 상태는 같은 크기·crop·변환을 검증한 `stateBlend: interpolate` 레이어다. fragment shader에서 두 premultiplied RGBA를 한 번 보간하고 한 번 합성한다. 두 상태를 source-over로 차례로 겹쳐 중간 상태의 alpha가 0.75로 줄어드는 구멍을 만들지 않는다. 서로 다른 기하에는 이 경로를 허용하지 않으며 기존 아트/삼중 상태 합성 동작은 기존 계약을 따른다. 50% 눈/입 내부 alpha 손실 0과 총 25개 GPU 상태를 검증한다.
