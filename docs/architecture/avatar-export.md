# 외부 아바타 변환·저장 계약

앱 0.20.0 · 모델 1.9 · `packages/avatar-export` · 검사 1.1.0/변환 0.3.0.

`CompatibilityService.pin`은 현재 입력/설정/버전과 경고 범위를 검증하고 프로젝트/자산 버퍼를 복제한다. `AvatarExportService`는 준비 요청 ID·세대·AbortController와 고정 입력을 소유한다. 취소한 세대의 늦은 응답/정리가 새 결과에 적용되지 않는다. 준비와 쓰기는 중복 실행하지 않는다. 취소는 다음 텍스처 경계에서 정리하고 준비/쓰기 완료 Promise를 기다린 뒤 정리 완료로 응답한다. 이미 확정한 파일은 취소로 되돌리지 않고 별도로 표시한다. 실행 중 무거운 변환/쓰기는 보류한다.

변환기는 공통 preview adapter를 통해 계층 좌표·불투명도·표시·상태·망을 읽고 정수 UUID의 INP 노드와 바인딩을 만든다. 비대칭 중립점을 포함한 물리 범위를 키점으로 유지한다. 가산으로 표현할 수 없는 교차 항은 차단한다. 곡선 키점 보간과 65단계 픽셀 상태는 제한 프로필 경고/실제 변환 미리보기의 대상이다. 원본/프로젝트 스키마를 수정하지 않는다.

내장 PNG는 독립 CRC/필터 디코더와 bounded inflate로 검사하며 JPEG는 호스트에서 canonical PNG로 변환한다. 색상/알파를 변환 사본에 굽고 중복 텍스처는 해시로 공유한다. INP 전체를 다시 읽어 섹션 길이·PNG·정수 UUID·노드/텍스처/바인딩 참조·매개변수 범위와 키점·유한 좌표·예산을 확인한다. 결과 보고서는 `org.2dsketcher.export.v1`, 대상 자동 동작/표정 설정은 공식 Session animation 확장에 내장한다.

변환 미리보기는 생성한 INP를 다시 해석한다. 메인만 텍스처 버퍼를 보유하고 요청 ID 아래의 `assets/avatar-export` grant로 읽는다. PMA 텍스처와 명시적 UV를 공통 GPU에 전달하며 매개변수 키점을 평가한다. 일반 프로젝트의 straight-alpha 경로와 별도 플래그이며 기존 렌더링을 바꾸지 않는다. 미리보기는 대상 SDK 실행을 가장하지 않는다. 저장에는 현재 입력과 정확한 결과 SHA에 대한 별도 검토가 필요하다.

저장은 메인의 네이티브 선택 위치만 사용한다. writer 잠금·이전 대상 해시·같은 볼륨의 소유 임시 파일·fsync·재검사·해시 CAS·rename으로 확정한다. 취소/실패는 기존 정상 파일을 지키며 무관한 파일을 삭제하지 않는다. 쓰기 시작 후 최신 편집은 고정 입력 결과와 구분한다. 이미 파일을 확정한 뒤 이력 기록이 실패하면 성공 파일을 쓰기 실패로 보고하지 않고 이력 경고를 표시한다.

결과 이력은 PC별 비공개 `avatar-exports.json`에 경로와 receipt를 보관한다. 공개 IPC에는 basename·해시·리비전/지문·버전·확인 방식만 제공한다. 읽기/수정/쓰기를 직렬화하여 확인/재연결/저장 경합을 막는다. 같은 파일의 이동은 해시 확인 후 경로만 재연결한다. 변경/누락/구버전/다른 입력은 현재 외부 확인으로 승격하지 않는다. 내용 지문은 리비전을 포함하되 저장 시각/저장 리비전만의 변경은 제외한다. 매 저장은 새 결과 ID와 미확인 상태다.

기본 앱 키/OS 키·카메라/마이크 설정은 외부로 자동 이전하지 않는다. 공식 대상의 장치 없는 기본 동작·표정과 실제 라이브 장치 바인딩 승인은 분리한다. 독립 대상 자동 시험은 제품 종료 증거와 대상 창 PNG/픽셀 비교를 별도 파일로 남기고 사용자 확인 receipt로 바꾸지 않는다. [사용법·범위](../planning/25-external-avatar.md).
