# 카메라·중립 보정·매핑 계약

앱 0.14.0 / 프로젝트 1.9. F-TRK-001~003, T-181~190. [현재 결정](../planning/05-decisions.md)과 [표정 우선순위](./expression-control.md)를 유지한다. M0는 HOLD다.

## 권한과 수명

renderer의 `getUserMedia({video:…, audio:false})`로 명시적으로 선택한 카메라를 연다. 창의 주 프레임과 `sketcher://app` 출처만 IPC를 사용한다. Electron은 연결 명령 이후 이 창의 video media만 허용하고 마이크·다른 권한은 거부한다. 장치 목록이 권한 전 비어 있으면 기본 카메라 연결 경로를 제공하고 연결 후 이름/목록을 갱신한다. 장치 존재·열기·영상 수신·얼굴 검출·대상 추적을 별도 상태로 표시한다.

`NotAllowedError`는 접근 거부, `NotFoundError`/`OverconstrainedError`는 선택 장치 없음으로 표시한다. `NotReadableError`는 열기 실패이며 점유/드라이버/운영체제 제한의 가능성으로 안내한다. 확정할 수 없는 점유 원인을 사실로 단정하지 않는다. `ended`, 3초간 새 영상 시각 없음, 추적 오류는 입력을 중단하고 수동 재연결을 제공한다. 자동 재연결과 복합 손실 전이는 20단계 후속이다.

추적은 대화상자를 닫아도 유지하며 주 화면에 사용/연결/중단 상태와 중지 버튼을 표시한다. 문서/세션 변경·앱 종료·중지는 모든 video track, 타이머, 대상/입력과 추적 프로세스를 해제한다. 늦은 비동기 결과는 세대 토큰으로 제외한다.

## 메모리 전용 추적 경로

사용자 video → 최대 640×480 JPEG(220KiB 이하) → 제한된 IPC → 전용 Python 프로세스 stdin → 고정 해시 MediaPipe 모델 → 파생값 JSON이다. 한 번에 한 요청만 처리한다. stdin 줄은 320KiB, stdout은 32KiB로 제한하고 순번·숫자·결과 필드를 검사한다. 모델 준비는 20초, 프레임 응답은 5초 제한이다. 모델은 VIDEO 모드이며 추론 시각을 단조 증가시킨다. 검출/존재/추적 임계값은 0.5, 최대 얼굴은 4개다. 랜드마크 전체·원본 영상·JPEG·음성을 응답/로그/프로젝트로 보내지 않는다. worker stderr도 기본 로그로 전달하지 않는다.

원본 미리보기는 사용자 선택으로만 분석에 쓰는 동일한 메모리 캔버스에 표시하며 좌우 반전도 이 요소와 위치 표시에만 적용한다. 얼굴 번호/위치를 같은 미러 좌표로 보여 주어 대상을 선택한다. 캐릭터 캔버스는 기존 AvatarRenderer와 숫자 매개변수만 사용한다. 영상 합성·OBS·방송 출력·녹화 기능을 이 경로에 넣지 않는다. 자동 UI 캡처는 합성 입력의 원본 표시를 끈 뒤 수행한다. 물리 카메라 시험에서는 화면을 캡처하지 않는다.

## 대상 정책과 한계

처음 한 얼굴만 보이면 선택한다. 처음 복수 얼굴이면 직접 고른다. 이후 사각형 IoU 0.25 이상·중심 거리 0.18 미만·면적비 0.5~2인 연속 후보 하나만 유지한다. 여러 후보가 겹치면 모호 상태로 입력을 제외하고 재선택을 요구한다. 다음 프레임에 한 얼굴만 남아도 자동으로 붙지 않는다. 다른 위치의 얼굴은 기존 대상을 대신하지 않는다. 얼굴 부재를 관찰한 뒤 마지막 유효 검출부터 0.5초가 지나거나, 새 관찰 없이 2초 넘게 입력이 끊기면 명시적으로 다시 선택한다. 단순한 0.5~2초 전송 지연만으로 같은 위치의 연속 유효 관찰을 부재로 오인하지 않는다. 동작 입력의 300ms 유효 시간은 이 대상 유지 시간과 별개다. 선택은 화면의 얼굴 위치를 기준으로 하고 모델 결과 배열 순서가 바뀌어도 인물 번호만 믿고 임의 전환하지 않는다.

이는 위치 연속성 정책이며 신원 인식이 아니다. 같은 위치에서 즉시 교대하는 사람·닮은 얼굴·심한 겹침을 생체 식별로 구분한다고 보장하지 않는다. 겹침/빠른 이동/아주 작은 얼굴·역광·가림·기울어진 카메라에는 검출/선택 제한이 있다. 두 명 이상일 때는 얼굴을 겹치지 않고 처음 대상이 자리를 유지하도록 안내한다.

## 중립 기준

보정 표본은 영상 획득 시각을 기준으로 하며 시작 전 프레임은 제외한다. 분석 지연이 300ms를 넘은 표본도 안정된 획득 구간의 기준 계산에는 쓸 수 있으나 실시간 동작 제어에서는 제외한다. 보정은 표정/편집 시험 이후 최종값이 아닌 **선택 대상의 원시 파생값**으로 수행한다. 12개 이상·1.5초 이상의 새 표본을 모은다. 눈을 뜨고(0.35 이상) 입을 편하게 다문 상태(0.25 이하), 정면에서 좌우 20°/기울기 15° 이내, 선택 얼굴 영역 RGB 평균 35 이상만 받는다. 배경이 어둡다는 이유로 밝은 얼굴의 보정을 막지 않도록 얼굴 영역을 사용한다. 화면 평균과 얼굴 밝기는 물리 조도계 수치가 아니라 휴리스틱이다.

고개 표준편차 2°/눈·입 비율 표준편차 0.07을 넘으면 표본을 다시 모은다. 얼굴 없음·어둠·무효 값·눈 감음·입 크게 벌림은 연속 표본을 초기화한다. 10초 안에 충분한 표본을 못 받으면 실패한다. 중앙값으로 새 후보를 만들고 **새 기준 적용**을 눌러야 기존 기준을 바꾼다. 취소·실패·대상 변경·프로젝트 변경은 후보만 버린다. 저장 실패도 이전 파일과 기준을 유지한다.

## 매핑과 우선순위

프로젝트 `tracking.channels`에 다섯 제어의 사용 여부·입력 범위·반전·강도(0~2)·평활 시간(0~500ms)·중립 여유(0~0.1)를 저장한다. 고개 범위는 보정 정면 기준 도 단위이며 기본 좌우 ±30°/기울기 ±20°다. 눈은 보정된 열림 비율(기준 1, 기본 범위 0~1.1), 입은 중립값을 뺀 jawOpen(기준 0, 기본 범위 -0.15~0.6)을 사용한다. 중립에서 양·음 방향을 각각 정규화하고 저장한 기본 자세 또는 매개변수 중립값을 중심으로 실제 최소/최대 단위로 변환한다. 반전·강도를 바꿔도 중립 입력의 기본 자세를 유지한다. 미지원/꺼진 항목은 보내지 않는다.

NaN/무한대·알 수 없는/범위 밖 파생값·역행 시각을 제외한다. 지수 평활은 시간 기반이고 단계당 최대 변화는 고개 초당 4, 눈/입 초당 20의 정규화 값에 dt 최대 0.1초를 적용한다. 중립 여유로 작은 떨림을 제거하고 마지막에는 매개변수 범위로 제한한다. 사진 복원/3D 자세 보증은 아니다.

결과는 공유 MotionPlayer의 camera 입력에 넣는다. 편집 시험 > 고정 표정 > 유효 카메라/입 정책 > 자동 > 기본값을 그대로 따른다. 실제 카메라 사용 중 합성 카메라는 보내지 않고 같은 순번 공급자를 사용한다. 영상 획득부터 300ms 넘게 지난 결과는 사용하지 않는다. 손실 단계별 유지·복귀 평활화·마이크 결합은 20단계에서 별도 검증한다.

## 저장 경계

프로젝트에는 매핑만 저장한다. 장치 기준은 PC의 `machine/camera-calibration.json`에 최대 32개 저장한다. 키는 이 앱 프로필의 Chromium 장치 ID·실제 해상도·추적 계약 버전의 SHA-256이며 장치 이름/개인 경로를 넣지 않는다. 다른 장치/해상도는 별도 기준을 사용한다. 새 파일을 쓴 뒤 rename으로 교체하고 손상된 기존 파일은 덮어쓰지 않는다.

카메라 변경은 원화·표정·구조를 변경하지 않는다. 프로젝트 매핑의 변경은 기존 CAS/undo/redo·복제·원자적 저장 흐름을 사용하며 장치 기준의 적용/취소는 프로젝트를 dirty로 만들지 않는다. 이전 1.0~1.8은 읽고 1.9 확장을 쓰는 변환본은 원본과 별도 저장한다.

## 근거

18개 Node 그룹·5개 Python 그룹을 추가한다. 실제 모델의 한 얼굴/두 독립 얼굴(고급 원화의 기술 입력)·검은 입력·잘못된 프로토콜, 대상 교대/겹침·보정 안정/취소·단위/평활/극단/순번·장치 파일 손상/프로젝트 분리를 검사한다. 자동 UI는 합성 canvas MediaStream과 실제 로컬 worker를 세 실제 제작 경로에서 사용하며 실제 환경 검증과 구분한다. [19단계 기록](../planning/19-camera-tracking.md)에 물리 카메라의 실패/재시험·사용자 관찰·지원 한계를 별도로 남긴다. 이 단계만으로 M0/성능·방송·전체 M3 통과를 선언하지 않는다.
