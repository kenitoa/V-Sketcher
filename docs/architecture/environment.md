# 환경 설정·개인정보·성능·지원 계약

2026-11-18 · 앱 0.21.0 · 프로젝트 모델 1.9 유지.

`packages/settings`는 기기 환경 스키마와 검증·직렬화 저장·허용 목록 기반 진단·제출 계측을 제공한다. `apps/desktop/environment.ts`는 신뢰한 메인 프레임 IPC·네이티브 폴더/파일 선택·실제 Electron 자원 계측·로컬 로그 삭제·고지 폴더를 연결한다. 렌더러의 환경 설정 화면은 기존 입력/실행/방송 제어를 함께 사용한다.

## 저장과 소유권

- `machine/environment.json`의 버전 1에 기본 장치 ID, 자동 복구 정책, 실행 미리보기 FPS/크기, 장치 연결 요청 허용, 최소 로컬 로그 허용과 비공개 기본 저장 폴더를 보관한다. 프로젝트 JSON에는 추가하지 않는다. 공유 설정 뷰와 진단 파일에 실제 폴더 경로를 반환하지 않는다.
- 정확한 필드·열거값·길이/타입 검증, FIFO 저장 큐, 같은 폴더의 `wx` 임시 파일·fsync·rename을 사용한다. Windows의 일시적인 rename 점유는 최대 200ms 범위로만 재시도하며 기존 대상을 삭제하지 않는다. 실패 시 이전 설정/무관한 파일을 보존하고 자기 임시 파일만 정리한다. 손상 설정은 기본값과 오류 상태로 열고 사용자가 적용하기 전 원본 파일을 덮어쓰지 않는다. 링크·UNC 폴더는 지원하지 않는다.
- 기본 폴더는 프로젝트/분리 PNG 묶음/PNG/INP/진단 저장 대화상자의 시작 위치다. 기존 프로젝트 저장 대상과 과거 결과 파일을 이동하지 않는다. 사라진 장치 ID를 다른 장치로 조용히 바꾸지 않고 재선택을 요구한다.
- 복구 정책은 표준(유휴 15초/최대 60초), 자주(5초/30초), 끄기다. 현재 진행 중인 복구 쓰기 완료를 기다린 뒤 정책을 적용한다. 끄기는 명시 저장·중요 변경 전 체크포인트·기존 정상본/복구본을 제거하지 않는다.

환경 설정 창이 열려 있는 동안 앱 전용/전역 조작을 보류한다. 포커스를 다른 앱으로 옮겨도 설정 편집 보류를 유지하고 창을 닫으면 현재 실행과 등록 상태로 복귀한다. OS 전역 키의 실제 전달 판정과 등록/보류 상태 시험을 구분한다.

## 장치·처리·동의

장치 요청 허용은 연결 자체가 아니다. 명시적인 연결 동작·메인의 입력 소유권·종류별 media 권한 검사를 유지한다. 요청을 끄면 메인 권한/추적 worker를 중지하고, 에디터와 실행본의 실제 카메라 트랙·마이크 트랙·AudioWorklet·AudioContext를 해제한다. 해제 버튼은 종료 Promise를 기다린다. 실행본은 입력 손실 규칙으로 제한 실행을 유지하며 임의 재연결하지 않는다.

초기 2D는 로컬 분석/추적/음량/렌더/파일 생성이다. 패키지에 모델과 원화를 포함한다. 외부 네트워크 요청 차단을 유지하며 OBS에는 loopback의 읽기 전용 캐릭터/제어만 제공한다. 영상은 메모리 추적 뒤 폐기하고 원음은 저장/재생/송출하지 않는다. 서버 진단 전송과 사용자 자산 학습은 **미제공·동의되지 않음**으로 고정하고 장치 허용과 분리한다. 로컬 로그 허용은 별도 설정이며 끄면 append를 멈춘다. 기존 최소 로그 삭제는 고정된 `events[.1~4].jsonl`만 대상으로 하며 프로젝트·캐시·복구본을 건드리지 않는다.

## 측정과 품질

실행 `RunSurface`의 제출 간격과 동기 CPU 제출 작업을 최근 5초/최대 600개로 집계한다. 제출 FPS와 p95에 구간·표본을 붙이고 비활성/오래된 값은 미측정으로 돌린다. GPU 완료·센서→OBS 전체 지연·OBS 인코더 FPS로 표시하지 않는다. Electron CPU API 합계/작업 집합 합계는 실제 API 값이며 Python worker·OBS 제외, 공유 메모리 중복 가능성을 표시한다. 텍스처 기본 레벨 RGBA 바이트는 추정이며 드라이버 GPU 메모리가 아니다.

수동 실행 미리보기는 15/30/60 FPS와 320×400/480×600/640×800을 제공한다. 원본 텍스처/편집 모델·PNG/INP는 변경하지 않으며 방송의 독립 크기/FPS는 기존 방송 설정에서 조절한다. 기본값 복원은 30 FPS/640×800이다. 자동 품질 조절은 제공하지 않는다. 제출 계측은 출시 성능 판정 계약을 대체하지 않는다.

## 진단과 지원

진단 JSON은 버전, 정해진 상태 열거값, 유한한 비음수 집계 수치만 새 객체로 추출한다. 프로젝트/장치 이름·ID, 파일 이름, 개인 경로, 주소·토큰, 원시 오류·로그·그림·카메라·PCM은 제외한다. 사용자가 포함 항목을 확인한 뒤 네이티브 저장하며 자동 전송하지 않는다. 새 파일은 임시 생성·fsync·rename하고 오류를 논리 코드로 표시한다.

지원 화면은 설치된 구성요소 버전, 모델 1.9, PNG/JPEG/.2dparts/.2dsketch, OBS 33.0.1과 Session 0.8.7/SDK 0.8.6 제한 프로필, 실제 기준 장비와 추가 검증 경계를 표시한다. 현재 프로젝트의 실제 자산 출처/제작자/이용 조건/미확인 권한을 보여 주며 번들 고지·모델/파츠/원화 출처 폴더로 연결한다. 권리를 자동 보증하지 않는다.
