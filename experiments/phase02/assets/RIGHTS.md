# 검증 자산 출처와 사용 범위

`single/`·`parts/`·`split/`의 PNG와 JSON은 프로젝트 작업 지시에 따라 작성한 [lab.py](../lab.py)의 기하 도형·색상·좌표 정의에서 직접 생성한다. 이 절차 제작 세트는 외부 캐릭터·사용자 원본 그림·사진·폰트·다운로드한 게임 자산·생성 모델의 출력물을 포함하지 않는다. 원본은 생성 코드와 고정 구성이다. `premium/`의 ImageGen 생성 자산은 아래 별도 출처로 구분한다.

- 출처 ID: `SRC-PROCEDURAL-001`.
- 제작: 이 프로젝트의 Codex 작성 코드로 절차 제작한 검증 캐릭터·파츠·오류 사례.
- 허용 목적: 이 프로젝트의 개발·기술 실험·회귀 검증·문서 및 저장소에 포함한 검증 자료 공유.
- 수정: 배경·가림·화풍·구도·해상도·분리 구조의 결정적 변형을 허용한다. 파생 관계는 manifest에 기록한다.
- 범위: 시험 자산이다. 사용자 조사의 실제 원본이나 완성 제품의 아트 라이브러리로 표시하지 않는다.
- 학습: 자체 모델 학습 데이터로 자동 편입하지 않는다. 학습 계획에서 별도로 결정한다.
- 제3자 조건: 자산에 제3자 저작물을 포함하지 않는다. 생성에 쓰는 Pillow 프로그램의 라이선스는 자산 출처와 구분하여 [라이선스](https://pillow.readthedocs.io/en/stable/about.html#license)를 확인한다.
- 외부 공개 라이선스 선택: 프로젝트 전체의 공개 라이선스를 이번 작업에서 새로 지정하지 않는다. 위 프로젝트 목적 이외의 별도 배포 조건은 배포 단계에서 정한다.

각 입력의 source·purpose·allowed_use·derived_from·파일 SHA-256은 생성되는 `manifest.json`에 연결된다. 다른 사람이 제공한 원본을 추가할 때는 출처·권한·허용 목적을 별도 확인하고 이 출처 ID를 재사용하지 않는다.

## 고품질 생성 자산 — SRC-IMAGEGEN-001

사용자가 이번 작업에서 고급 이미지 품질을 요청하여 기본 제공 ImageGen 도구로 새로 생성했다. 제공받은 외부 인물·캐릭터 원본은 사용하지 않았다. [출처·용도·제한](./premium/catalog.json)과 [최종 프롬프트·편집 기록](./premium/generation-prompts.md)을 보존한다. 이 프로젝트의 기술 평가·이미지 품질 검토·문서용으로 등록하며, 모델 학습·외부 자산 판매·일반 공개 라이선스 부여까지 자동 허용한 것으로 해석하지 않는다. 도구 사용과 출처 확인은 제3자 권리 전반에 대한 법적 보증을 뜻하지 않는다. 실제 사용자 입력 자료로 분류하지 않는다.
